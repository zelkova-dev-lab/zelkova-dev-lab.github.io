## H-Index
{: #h-index }

> **H-Index가 N이라는 건, N번 이상 플레이한 게임이 N가지 있다는 뜻입니다.**

논문 인용 지수에서 온 개념으로, **다양성과 반복을 동시에** 재는 숫자입니다.

| 상황 | H-Index |
|---|---|
| 한 게임만 100번 | 1 |
| 100개 게임을 1번씩 | 1 |
| 10개 게임을 10번씩 | **10** |

그래서 H-Index를 올리려면 **좋아하는 게임 여러 개를 꾸준히** 해야 합니다.
챌린지에도 H-Index 목표가 따로 있습니다 ([7.1](../../07-challenges/types/)).

## 승률

**내가 이긴 판 ÷ 전체 판**입니다. "나"는 참가자 목록의 **첫 번째 자리**입니다.

- 협력 게임은 **팀이 이기면 나도 이긴 것**으로 셉니다
- 승자를 기록하지 않은 판은 진 것으로 셉니다 (`없음`으로 저장됨)

{: .note }
> **화면마다 승패 기준이 미묘하게 다를 수 있습니다.**
> 모임 리더보드는 "참가자를 식별할 수 있는 판"만 세기 때문에,
> 같은 모임의 판수가 다른 카드보다 적게 나올 수 있습니다.

## 미보유 플레이
{: #미보유-플레이 }

**그 판을 하던 시점에** 갖고 있지 않았던 기록입니다. 홈 화면 미니카드에서 볼 수 있습니다.

판정은 거래 이력으로 합니다.

```
구매 ────────────── 방출        구매
  │                  │            │
  └── 보유 구간 ──────┘            └── 보유 구간 ──▶
      ↑ 이 사이의 플레이는 '보유'
```

| 상황 | 미보유로 잡히나 |
|---|---|
| 사기 전에 남의 것으로 해 본 판 | **예** |
| 갖고 있을 때 한 판 | 아니요 |
| 팔고 나서 친구 것으로 한 판 | **예** |
| 갖고 있을 때 한 판인데, 나중에 팔았음 | **아니요** (소급 적용되지 않습니다) |

구매일·방출일 당일의 플레이는 **보유**로 봅니다.
거래 이력이 아예 없는 게임은 현재 보유 표시를 따릅니다.

## 플레이 스타일 6축

내 기록에서 뽑아낸 성향 지표입니다.

| 축 | 무엇을 재나 |
|---|---|
| **복잡도** | 주로 하는 게임의 난이도(weight) |
| **사교성** | 평균 참가 인원 |
| **호흡** | 한 판에 걸리는 시간 |
| **협력성** | 협력 게임의 비중 |
| **다양성** | 서로 다른 게임을 얼마나 넓게 하는가 |
| **최신성** | 최근 출시작을 얼마나 하는가 |

화면의 **플레이 스타일이란?** 안내에서 각 축의 설명을 볼 수 있습니다.

## 장롱 지수

**오래 갖고 있는데 잘 안 하는 게임**을 찾아 줍니다.
기준은 **연환산 플레이 횟수** — 보유 기간 대비 플레이 횟수입니다.

| 목록 | 뜻 |
|---|---|
| **장롱 TOP 3** | 연환산 플레이가 가장 적은 게임 (같으면 오래 보유한 순) |
| **알뜰 TOP 3** | 연환산 플레이가 가장 많은 게임 — 본전 뽑은 게임 |

현재 보유 중이면서 **90일 이상** 갖고 있는 게임이 3개 이상일 때만 나타납니다.

## 보유 기간 통계

거래 이력에서 **구매 → 방출** 쌍을 짚어 계산합니다.

| 항목 | 뜻 |
|---|---|
| **보유 게임 수** | 계산 대상이 되는 게임 수 |
| **평균 보유** | 지금 갖고 있는 게임들의 평균 보유 기간 |
| **최장 보유** | 가장 오래 갖고 있는 게임 |
| **완결 건수** | 구매 → 방출까지 끝난 사이클 수 |
| **평균 소장 기간** | 완결된 사이클의 평균 |
| **최단기 방출** | 가장 빨리 판 게임 |

시작일은 **수령일이 있으면 수령일, 없으면 거래일**입니다 (배송 대기를 보유로 세지 않기 위해).
처분 통계는 완결 사이클이 3개 이상일 때 나옵니다.

이 카드는 **기간 필터를 따르지 않고 전체 기간**을 봅니다.

## 보유 게임 수는 왜 화면마다 다른가
{: #보유-게임-수는-왜-화면마다-다른가 }

**본판만 세는 곳**과 **확장까지 세는 곳**이 다르기 때문입니다.

| 화면 | 기준 |
|---|---|
| 컬렉션 **보유 중** 탭 숫자 | **본판만** |
| 홈 화면 **보유 게임** 미니카드 | **본판만** |
| 내 정보 컬렉션 통계 | **본판만** |
| 챌린지 · 배지 · 검색 필터 · 기록할 게임 고르기 | **확장 포함** |

"게임 몇 종 있어?"에는 본판 수가, "플레이할 수 있는 항목이 몇 개야?"에는 확장 포함 수가 맞기 때문입니다.
자세한 내용은 [2.4 본판과 확장](../../02-collection/expansions/)에 있습니다.

## 판수를 더했는데 안 맞을 때
{: #판수를-더했는데-안-맞을-때 }

의도된 중복이 두 군데 있습니다.

| 어디서 | 왜 |
|---|---|
| **역할별 성적** | 한 판에 역할을 여럿 맡았으면 각 역할에 1판씩 들어갑니다 |
| **모임별 성적** | 친구가 여러 모임에 속하면 같은 판이 여러 모임에 잡힙니다 (`판 중복 가능` 캡션) |

반대로 **모임 리더보드**는 참가자를 식별할 수 있는 판만 세므로 **더 적게** 나올 수 있습니다.

## 게임 이름이 통계에서 합쳐지는 기준

게임별 집계는 **이름이 아니라 게임 ID**로 합니다.
같은 게임을 영어로도 한글로도 기록했더라도 하나로 묶입니다.
화면에 보이는 이름은 항상 카탈로그의 최신 이름(한글명이 있으면 한글명)입니다.
