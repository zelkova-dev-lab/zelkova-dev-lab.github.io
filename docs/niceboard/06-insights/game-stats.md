# 6.2 게임별 통계와 고급 필터
{: .no_toc }

**{게임명} 통계** 화면. 한 게임을 깊게 파고드는 곳입니다.
"내가 이 게임에서 어떤 진영일 때 잘하나", "4인일 때랑 3인일 때 승률이 다른가" 같은 질문에 답합니다.

## 들어가는 길

| 어디서 | 어떻게 |
|---|---|
| **게임 상세** | 플레이 통계 요약 카드를 탭하거나 **상세 통계** 버튼 |
| **인사이트 탭** | 가장 많이 즐긴 게임 · 게임별 승률의 행을 탭 (게임 상세를 거치지 않음) |
| **모임 상세 / 인사이트 모임 카드** | 최다 플레이 게임 행을 탭 — **그 모임 필터가 걸린 채로** 열립니다 |

마지막 경우엔 모임 필터가 이미 적용돼 있으므로, 전체를 보고 싶으면 필터 칩을 해제하세요.

## 카드들

### 플레이 통계

총 플레이 · 내 승률 · 최근 플레이 · **플레이 일수**(며칠에 걸쳐 했나) · 총 플레이 시간 · 평균 플레이 시간

### 추이 · 분포 (모든 게임 공통)

| 카드 | 내용 |
|---|---|
| **월별 플레이** | 최근 12개월 막대. 초록이 이긴 판 |
| **인원수별 승률** | 2인 · 3인 · 4인… |
| **함께한 사람별 성적** | |
| **모임별 성적** | 모임이 있을 때만 |
| **모임 순위** | 이 게임 한정 모임 리더보드 |
| **내 점수 분포** | 점수 히스토그램. 숫자 점수가 3개 미만이면 생략 |
| **내 순위 분포** | 순위 기록 게임에서 등수 히스토그램 |

### 역할 · 플레이 방식 통계

기록에 그런 정보가 있을 때만 나타납니다.

| 카드 | 내용 |
|---|---|
| **역할별 성적** | 스코프 `나 / 전체 / 참가자` 중 선택 |
| **역할 조합** | 한 판에 함께 쓰인 역할 조합별 승률 (솔로 1인 다역도 잡힙니다) |
| **플레이 방식별 승률** | 맵 · 시나리오별 |
| **확장팩별 승률** | |
| **{텍스트 항목}별 성적** | 템플릿의 텍스트 항목마다 자동 생성 |
| **{게임 공통 항목}별 승률** | 판 공통 항목마다 자동 생성 |

## 카드 조작법

모든 통계 카드가 같은 방식으로 동작합니다.

| 조작 | 결과 |
|---|---|
| **성적 ↔ 분포 토글** (헤더 오른쪽) | **성적** = 승률 막대 목록 / **분포** = 판수 비중 도넛 |
| **행 탭** | 그 조건의 플레이 목록이 아래에서 올라옵니다 (드릴다운) |
| **더보기 (N) / 접기** | 상위 5개 너머를 봅니다 |

드릴다운 시트에서 기록을 탭하면 상세 시트가 열리고, 거기서 **편집**까지 이어집니다.

{: .note }
> 드릴다운 위쪽에는 **교차 통계**가 나옵니다.
> 플레이 방식을 열면 "이 방식에서의 역할 성적", 역할을 열면 "이 역할이 쓰인 플레이 방식"이 함께 보입니다.

## 고급 필터 — 10가지 조건

화면 위쪽 **필터** 버튼으로 엽니다. 조건을 걸면 **화면의 모든 카드**가 그 범위만 집계합니다.

| # | 조건 | 설명 |
|---|---|---|
| 1 | **기간** | 전체 / 최근 1년 / 30일 / 7일 / 직접 설정 |
| 2 | **결과** | 전체 / 승 / 패 |
| 3 | **플레이 방식** | |
| 4 | **역할** | **이 역할이 등장한 판** — 내가 맡은 역할만이 아닙니다 |
| 5 | **게임 공통 · {항목}** | 항목 사이는 AND, 한 항목 안의 여러 값은 OR |
| 6 | **모임** | 멤버가 1명 이상 참가한 판 |
| 7 | **함께한 사람** | 나를 제외한 참가자 |
| 8 | **확장팩** | |
| 9 | **인원수** | |
| 10 | **장소** | 빈 값은 `미지정`으로 묶입니다 |

**조건끼리는 AND, 한 조건 안의 여러 값은 OR**입니다.
예: `역할 = 엘프 또는 드워프` **그리고** `인원수 = 4인`

{: .warning }
> **필터 시트는 '필터 적용'을 눌러야 반영됩니다.** 조작하고 그냥 닫으면 버려집니다.
> 조작할 때마다 화면 전체를 다시 계산하지 않기 위한 규칙이며, 앱의 모든 필터 시트가 같습니다.

### 필터 상태 확인

필터를 걸면 버튼 아래에 조건별 칩이 나옵니다. 칩의 **X**로 그 조건만 해제하고,
**전체 해제**로 전부 풉니다.

그 아래 한 줄이 효과를 알려 줍니다.

```
아래 통계는 모두 조건에 맞는 24판 기준 · 전체 51판
```

판수가 안 줄었을 때는 문구가 바뀝니다.

```
전체 51판이 모두 조건에 맞아 판수는 그대로입니다
```

<!-- screenshot: game-stats.png -->

{: .note }
> **판수가 안 줄어도 필터는 걸려 있습니다.**
> 예를 들어 `함께한 사람 = 민수`로 걸었는데 모든 판에 민수가 있었다면 판수는 그대로입니다.
> 대신 각 카드는 조건에 맞는 값만 보여 줍니다.

### 필터를 걸었을 때 카드가 좁혀지는 방식

- **인원수 · 플레이 방식 · 장소 · 게임 공통** — 한 판에 값이 하나뿐이라 카드가 자연히 한 줄로 접힙니다
- **함께한 사람 · 역할 · 확장팩 · 모임** — 한 판에 값이 여럿일 수 있어, 카드가 **고른 값만** 보여 줍니다

조건이 한 값으로 좁혀져 행이 하나만 남아도 **카드를 숨기지 않습니다.**
콕 집어 고른 대상이 화면에서 사라지면 "통계에서 빠졌다"로 읽히기 때문입니다.

## 알아 둘 집계 규칙

| 카드 | 규칙 |
|---|---|
| **모임 순위** | `내 기록 기준 · 참가자 식별이 가능한 판만 집계` — 참가자 이름이 남아 있는 판만 셉니다 |
| **모임별 성적** | `판 중복 가능` — 친구가 여러 모임에 속할 수 있어, 모임별 판수를 더하면 전체 판수보다 클 수 있습니다 |
| **역할별 성적** | 한 판에 역할이 여럿이면 각 역할에 1판씩 |
| **점수 분포** | 순위 기록 게임의 기록은 제외됩니다 (점수 칸에 등수가 들어 있기 때문) |

카드마다 이런 캡션이 직접 붙어 있으니, 숫자가 달라 보이면 캡션을 읽어 보세요.
