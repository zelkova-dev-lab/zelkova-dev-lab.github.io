# 6. 통계와 인사이트
{: .no_toc }

기록이 쌓이면 앱이 알아서 분석해 줍니다. 통계를 보는 곳은 세 군데입니다.

- **인사이트 탭** — 내 보드게임 생활 **전체**를 봅니다.
- **게임 통계 화면** — **한 게임**을 깊게 파고듭니다. 10가지 조건으로 걸러 볼 수 있습니다.
- **모두의 통계** — 나이스보드를 쓰는 **사람들 전체**의 집계를 봅니다.

| 절 | 내용 |
|---|---|
| [6.1 인사이트 탭](insights-tab/) | 여섯 개 카테고리와 기간 필터 |
| [6.2 게임별 통계와 고급 필터](game-stats/) | 역할 · 플레이 방식 · 모임별 성적, 10차원 필터 |
| [6.3 지표 사전](metrics/) | H-Index · 승률 기준 · 플레이 스타일 · 장롱 지수 · 미보유 플레이 |
| [6.4 모두의 통계](everyones-stats/) | 인기 게임 · 뜨는 게임 · 장르 · 요일 · 거래 성향 |

{: .note }
> 카드마다 집계 범위가 조금씩 다릅니다. 화면 기간 필터를 따르지 않는 카드에는
> **"현재 상태 기준"**, **"전체 기간 기준"**, **"내 기록 기준"** 같은 캡션이 붙어 있으니
> 숫자가 안 맞아 보일 때 그 줄을 먼저 확인하세요. 자세한 규칙은 [6.3 지표 사전](metrics/)에 정리했습니다.
