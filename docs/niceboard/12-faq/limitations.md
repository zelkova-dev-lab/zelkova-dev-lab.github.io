# 12.3 알려진 제한사항
{: .no_toc }

지금 버전에서 안 되는 것들입니다. 버그가 아니라 아직 만들지 않은 부분입니다.

1. TOC
{:toc}

---

## 플랫폼

| 항목 | 상태 |
|---|---|
| 안드로이드 | ✅ 지원 |
| iOS | ❌ 미지원 |
| 웹 · PC | ❌ 미지원 |

---

## 계정

- **Apple 로그인** 없음
- **이메일 인증 절차** 없음 — 가입 즉시 사용할 수 있습니다
- **계정 간 데이터 이전 기능** 없음 — 백업 파일로만 옮길 수 있습니다

---

## BGG 연동

- **한 방향만 지원합니다** — BGG → 나이스보드.
  앱에서 남긴 기록이 BGG로 올라가지는 않습니다
- BGG 컬렉션 상태 중 **owned · wishlist · prev-owned**만 가져옵니다

---

## 커뮤니티

- **신고 · 차단 기능이 없습니다** — 커뮤니티 점수 시트와 한글명 제안에 부적절한 내용이 있으면
  [의견 보내기](../feedback/)로 알려 주세요
- 채팅이나 친구 활동 피드는 없습니다

---

## 기록과 통계

| 제한 | 설명 |
|---|---|
| **확장팩은 텍스트로만 저장** | 확장 이름을 글자로 기록하므로, 게임 항목과 정식으로 연결되지는 않습니다 |
| **같은 게임 여러 개 관리 불가** | 같은 게임의 다른 판본·복수 소장을 따로 관리할 수 없습니다 |
| **인사이트 기간이 고정 4종** | 전체 / 최근 1년 / 30일 / 7일. 직접 기간 지정은 게임 통계 화면에서만 가능합니다 |
| **오프라인 충돌 처리 없음** | 두 기기에서 동시에 같은 항목을 고치면 나중 것이 남습니다 |

---

## 데이터 이동

- **BG Stats 호환 백업**은 두 앱이 공통으로 가진 개념만 담습니다.
  모임 · 챌린지 · 텍스트 항목 · 게임 공통 항목 같은 나이스보드 고유 데이터는
  **나이스보드 전체 백업**으로만 온전히 보존됩니다
- 자동 안전 스냅샷은 **기기 안**에 최대 3개만 보관됩니다. 기기를 바꾸면 사라집니다

---

## 삭제

- 제출한 **의견(피드백)은 계정을 탈퇴해도 남습니다** — 접수된 버그 리포트라 보존됩니다
- 커뮤니티 기여물(한글명 제안 · 공유한 점수 시트)도 남습니다.
  탈퇴 전에 직접 지워야 합니다 → [11.5 계정 탈퇴](../../11-data-settings/account-deletion/)

---

## 실험 중인 기능

일부 기능은 기본으로 꺼져 있어 보이지 않습니다.
반응을 보며 정식 도입 여부를 검토하는 단계이며, 이 문서에서는 다루지 않습니다.
