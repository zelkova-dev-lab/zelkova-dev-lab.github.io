# 9. 친구 · 모임 · 장소
{: .no_toc }

자주 같이 노는 사람과 자주 가는 곳을 등록해 두면,
기록을 남길 때 이름을 매번 타이핑하지 않아도 되고 **전적 통계**까지 따라옵니다.

| 절 | 내용 |
|---|---|
| [9.1 친구 등록](friends/) | 이름으로 추가 · 유저 찾기로 연결 · 친구 상세의 1:1 전적 |
| [9.2 모임](groups/) | 모임 만들기, 멤버 편집, 리더보드, 모임별 최다 플레이 게임 |
| [9.3 전적 집계 규칙](stats-rules/) | 이름 매칭 방식과 판수가 달라 보이는 이유 |
| [9.4 장소](places/) | 장소 등록과 기록 입력에서의 사용 |

{: .warning }
> 전적은 **플레이 기록의 참가자 이름이 친구 이름과 같을 때** 자동으로 연결됩니다.
> 이름을 다르게 적으면 같은 사람으로 세지 않습니다 — 자세한 내용은 [9.3](stats-rules/)에 있습니다.
