# 9.4 장소
{: .no_toc }

자주 가는 곳을 등록해 두면 기록할 때 칩으로 한 번에 고를 수 있습니다.

1. TOC
{:toc}

---

## 장소 목록

**내 정보 → 플레이 도구 → 장소 목록**

| 조작 | 결과 |
|---|---|
| 오른쪽 위 **+** | 장소 추가 (예: `우리집`, `보드게임 카페 ○○`) |
| 카드 **탭** | 이름 변경 |
| **🗑** | 삭제 |

빈 목록일 때 안내:
*"자주 가는 보드게임 카페나 모임 장소를 등록하면 플레이 기록 입력할 때 빠르게 선택할 수 있어요."*

---

## 삭제해도 기록은 안 바뀝니다

{: .note }
> 장소를 지워도 **이미 작성된 플레이 기록의 장소 텍스트는 그대로 유지됩니다.**
> 목록에서 사라질 뿐이며, 과거 기록과 통계는 영향을 받지 않습니다.

---

## 기록할 때 쓰기

기록 입력 화면의 **장소** 칸에서:

- 등록된 장소가 **칩 줄**로 나옵니다 — 탭하면 채워집니다
- 자유롭게 타이핑할 수도 있습니다
- 등록되지 않은 이름을 입력하면 오른쪽에 **장소로 등록** 아이콘이 나타납니다

등록하면 `…장소로 추가됨`, 이미 있으면 `…은(는) 이미 등록되어 있습니다` 메시지가 뜹니다.

**📋 장소 선택** 버튼으로 목록 시트를 열 수도 있습니다.

---

## 장소가 만드는 통계

| 어디 | 무엇 |
|---|---|
| **인사이트 → 플레이 패턴 & 분포** | 장소별 플레이 분포 도넛 |
| **인사이트 → 승률 및 경쟁 분석** | 장소별 승률 Top 5 |
| **인사이트 요약 카드** | 장소 개수 |
| **게임 통계 고급 필터** | 장소 차원 |
| **배지** | 원정대(장소 수) · 단골손님(한 장소 반복) |

{: .warning }
> **글자가 정확히 같아야 같은 장소로 셉니다.**
> `우리집`과 `우리 집`은 별개입니다. 등록해 두고 칩으로 고르면 이런 문제가 없습니다.
>
> 장소를 비워 두면 `미지정`으로 저장되며, 장소 통계와 배지에서는 제외됩니다.
