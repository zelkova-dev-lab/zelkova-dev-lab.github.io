# 9.1 친구 등록
{: .no_toc }

**내 정보 → 소셜 → 친구·모임 목록**

1. TOC
{:toc}

---

## 두 가지 방법

**친구 추가** 버튼(또는 오른쪽 위 아이콘)을 누르면 고를 수 있습니다.

| 방법 | 설명 |
|---|---|
| **이름 직접 입력** | *"자주 같이 플레이하는 사람의 이름만 등록합니다."* 상대가 앱을 안 써도 됩니다 |
| **유저 찾기에서 추가** | *"검색 허용을 켠 사용자에 연결합니다."* 나이스보드 사용자와 계정을 연결합니다 |

대부분은 **이름 직접 입력**으로 충분합니다. 전적 통계는 이름만으로도 다 계산됩니다.

---

## 유저 찾기

**내 정보 → 소셜 → 유저 찾기**로도 바로 들어갈 수 있습니다.

| 검색 축 | 방식 |
|---|---|
| **이름** | 앞부분 일치 |
| **보드라이프 ID** | 정확히 일치 |

*"검색 허용을 켠 사용자만 노출됩니다."*

결과 카드의 **추가** 버튼으로 친구가 되고, 이미 연결된 사람에게는 **연결됨** 뱃지가 붙습니다.

{: .note }
> 내가 검색되게 하려면 **내 정보 → 소셜 → 다른 사용자가 내 프로필을 검색하도록 허용**을 켜세요.
> 기본은 꺼져 있습니다.

---

## 친구 목록에서

각 친구 카드에서:

- **탭** → 친구 상세
- **🔗 아이콘** → 그 친구의 보드라이프 프로필 (보드라이프 ID가 있을 때)
- **🗑** → 삭제

{: .warning }
> 친구를 삭제하면 **소속된 모임에서도 함께 빠집니다.**
> 이미 저장된 플레이 기록의 참가자 이름은 그대로 남습니다.

---

## 친구 상세 화면

친구를 탭하면 그 사람과의 기록이 나옵니다.

| 카드 | 내용 |
|---|---|
| **1:1 전적** | 함께한 판 · 내 승수와 승률 · 상대 승수 |
| **소속 모임** | 모임 칩을 탭해서 넣고 뺍니다 |
| **게임별 전적** | 게임마다 `나 N승 · 친구 N승` Top 5 |
| **최근 함께한 기록** | 승/패 표시와 함께 |

오른쪽 위에서 **이름 변경**과 **삭제**를 할 수 있습니다.

기록이 없으면 이렇게 안내합니다 —
*"플레이 기록의 참가자 이름이 친구 이름과 같으면 자동으로 집계돼요."*

---

## 친구를 등록하면 좋은 이유

| 이점 | 설명 |
|---|---|
| **입력이 빨라짐** | 기록할 때 목록에서 고르기만 하면 됩니다 |
| **전적이 정확해짐** | 이름이 늘 같으므로 통계가 흩어지지 않습니다 |
| **모임을 만들 수 있음** | 모임 멤버는 친구 중에서 고릅니다 |
| **배지** | 마당발 · 환상의 짝꿍 배지가 정확히 집계됩니다 |

{: .warning }
> **이름을 매번 다르게 적으면 다른 사람으로 셉니다.**
> `민수` / `민수님` / `Minsu`는 전부 별개입니다 → [9.3 전적 집계 규칙](../stats-rules/)

## 기록에서 친구 만들기

이미 남긴 기록의 참가자를 친구로 만들 수도 있습니다.
기록 상세 시트의 **모임 만들기**를 쓰면, 친구로 등록되지 않은 참가자가
**자동으로 친구로 생성되어** 모임에 들어갑니다 → [9.2 모임](../groups/)
