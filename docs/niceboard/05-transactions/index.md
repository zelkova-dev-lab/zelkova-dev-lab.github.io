# 5. 거래와 가계부
{: .no_toc }

게임과 용품을 **언제 · 얼마에 · 어디서** 사고 팔았는지 기록하면,
앱이 지출 · 회수액 · 손익을 자동으로 계산해 줍니다.

거래를 등록하면 **보유 여부도 함께 정해집니다.** 구매 거래를 넣으면 보유가 되고,
방출 거래를 넣으면 보유에서 빠집니다. 보유 스위치를 직접 만지지 않아도 되는 이유입니다.

| 절 | 내용 |
|---|---|
| [5.1 게임 거래 등록](game-transactions/) | 구매 · 방출 · 선주문/펀딩 입력 항목 |
| [5.2 용품 거래](accessories/) | 슬리브 · 매트 · 정리함 · 주사위 · 트레이 · 기타 |
| [5.3 거래 기록 화면](ledger-screen/) | 요약 · 차트 · 필터 · 정렬 · 다중 선택 삭제 |
| [5.4 금액 용어 사전](terms/) | 지출 · 수익 · 손익 · 소비액 · 세이브 |

{: .note }
> 거래 기록은 **내 기록 → 거래** 탭에 모입니다. 게임과 용품은 화면 위쪽 세그먼트로 전환합니다.
