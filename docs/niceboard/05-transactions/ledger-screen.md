# 5.3 거래 기록 화면
{: .no_toc }

**내 기록 → 거래** 탭. 등록한 모든 거래가 여기 모입니다.

1. TOC
{:toc}

---

## 화면 구성

위에서부터 이렇습니다.

```
[ 게임 | 용품 ]              ← 세그먼트 토글
────────────────────────────
요약 카드 (전체 합계)
차트 3종
────────────────────────────
[ 트랜잭션 | 게임별 ]  [필터]  ← 보기 모드 + 추가 필터
[전체][구매][방출][선주문/펀딩]
[🎲 게임 선택]           [정렬 ▾]
표시 중 N건 / 전체 M건         [선택]
────────────────────────────
거래 목록
```

용품 탭은 보기 모드와 정렬이 없어 조금 다릅니다 — `[전체][구매][방출][선주문/펀딩]` · `[카테고리 칩]` · `[용품 선택]` 세 줄입니다.

---

## 요약 카드

| 항목 | 뜻 |
|---|---|
| **구매 N건 / 방출 N건 / 선주문/펀딩 N건** | 종류별 건수 (선주문이 없으면 그 칸은 안 나옵니다) |
| **소비액** | 수집 누적액 − 방출 회수액. 음수면 **`세이브 N원`** |
| **수집 누적액** | 돈이 나간 거래의 합 |
| **방출 회수액** | 방출로 돌려받은 금액의 합 |

용어의 정확한 정의는 [5.4 금액 용어 사전](../terms/)에 있습니다.

![거래 기록 화면](/docs/niceboard/assets/screenshots/ledger.webp){: .screenshot }
*세그먼트로 게임과 용품을 오가고, 요약 카드 아래에 차트와 목록이 이어집니다*

{: .note }
> 요약 카드는 **필터를 따르지 않고 전체 거래 기준**입니다.
> 단, 게임(또는 용품) 필터를 걸면 제목이 `게임명 합계`로 바뀌고 그 게임의 전체 거래를 기준으로 다시 계산합니다.
> 지금 조건에 걸린 결과 수는 목록 위의 `표시 중 N건 / 전체 M건` 캡션이 알려 줍니다.

---

## 차트 세 가지

| 차트 | 보여 주는 것 |
|---|---|
| **월별 지출** | 달마다 얼마나 썼는지 막대 그래프 |
| **신규 / 중고** | 새 제품과 중고에 쓴 비율 도넛 |
| **채널별** | 어느 경로에서 얼마나 샀는지 가로 막대 |

---

## 보기 모드 두 가지

| 모드 | 목록 형태 |
|---|---|
| **트랜잭션** | 거래 한 건이 한 카드. 시간순으로 쭉 |
| **게임별** | 게임 한 개가 한 카드. 펼치면 그 게임의 거래 목록 |

"이 게임에 얼마 썼나"가 궁금하면 **게임별**, "지난달에 뭘 샀더라"면 **트랜잭션**이 편합니다.

## 걸러 보기

### 상시 노출 필터

- **종류 칩** — 전체 / 구매 / 방출 / 선주문/펀딩
- **게임 선택 칩** (용품 탭에서는 **용품 선택**) — 필터 칩들의 **맨 아래 줄 왼쪽**에 있습니다. 특정 게임의 거래만 봅니다. 시트 안에서 이름 검색이 되고, 한글명으로도 찾을 수 있습니다. 띄어쓰기를 빼거나 이름 중간부터, 초성으로 쳐도 됩니다 → [공통 조작](../../01-getting-started/screen-map/#이름을-정확히-몰라도-찾아-줍니다). 고르면 요약 카드 제목이 `게임명 합계`로 바뀝니다
- **정렬** — 최신 거래일 / 오래된 거래일 / 가격 높은 순 / 가격 낮은 순

### 추가 필터 시트

**필터** 버튼(활성 개수가 뱃지로 표시됨)을 누르면 열립니다.

| 조건 | 값 |
|---|---|
| 거래일 | 기간 선택 또는 전체 기간 |
| 판매자/구매자 | 텍스트 부분 일치 |
| 경로 | 여러 개 선택 (자주 쓰는 순으로 정렬) |
| 가격 범위 | 0원 ~ 50만 원 이상 |
| 상품 상태 | 전체 / 신규 / 중고 |
| 거래 방식 | 전체 / 온라인 / 오프라인 |

{: .warning }
> **필터 시트는 '필터 적용'을 눌러야 반영됩니다.**
> 조건을 바꾸고 그냥 닫으면 **버려집니다.** 앱의 모든 필터 시트가 같은 규칙입니다.
> `필터 전체 초기화`도 시트 안의 작업 사본만 지우므로, 그 뒤 `필터 적용`을 눌러야 실제로 해제됩니다.

용품 탭에는 추가로 **카테고리 칩**이 있습니다.

---

## 여러 건 한꺼번에 지우기

1. 건수 캡션 오른쪽의 **선택** 버튼을 누르거나, 카드를 **길게 누릅니다**
2. 지울 항목들을 탭해서 고릅니다 (동그란 체크 표시가 붙습니다)
3. 화면 아래 바에서 **삭제**

아래 바에는 `선택 취소` · `N건 선택` · `전체 선택 / 전체 해제` · `삭제`가 있습니다.

**게임별 모드**에서는 조금 더 편합니다.

- 게임 카드 헤더를 **길게 누르면** 그 게임의 표시 중인 거래가 **한꺼번에 선택**됩니다
- 선택 모드에서 헤더 썸네일을 탭하면 게임 단위로 켜고 끕니다 (일부만 선택된 상태는 대시로 표시)

{: .note }
> 선택은 **보기 모드를 바꿔도 유지**됩니다. 반면 게임 ↔ 용품 세그먼트를 바꾸면 해제되고,
> 필터 때문에 화면에서 사라진 거래는 선택에서 자동으로 빠집니다 — 안 보이는 것이 지워지지 않도록 하기 위해서입니다.
