# 5.2 용품 거래
{: .no_toc }

슬리브 · 플레이매트 · 정리함처럼 게임은 아니지만 돈이 드는 물건도 기록할 수 있습니다.

1. TOC
{:toc}

---

## 카테고리

| 카테고리 | 예 |
|---|---|
| **슬리브** | 카드 보호 슬리브 |
| **매트** | 플레이매트, 네오프렌 매트 |
| **정리함** | 인서트, 오거나이저 |
| **주사위** | 커스텀 다이스 |
| **트레이** | 다이스 트레이 |
| **기타** | 위에 없는 모든 것 |

---

## 등록하기

**내 기록 → 거래 탭 → 용품 세그먼트 → 오른쪽 위 +**

게임과 달리 카탈로그가 없으므로 **이름을 직접 입력**합니다.
하나의 시트에서 카테고리 · 이름 · 거래 정보를 모두 넣습니다.

| 항목 | 설명 |
|---|---|
| **카테고리** | 위 6종 중 하나 |
| **이름** | 직접 입력 |
| **거래 종류** | 구매 / 방출 / 선주문·펀딩 |
| **거래일** | 필수. 안 고르면 빨간 테두리로 표시됩니다 (선주문이면 **결제일**) |
| **예상 수령일** | 선주문일 때만, **필수** |
| **상태** | 신규 / 중고 — 돈이 나가는 거래에만 |
| **경로 · 방식 · 상대 · 가격 · 메모** | 게임 거래와 동일 |

---

## 게임 거래와 다른 점 하나

{: .warning }
> **용품은 마지막 거래를 지우면 용품 자체가 사라집니다.**
> 게임은 거래를 다 지워도 항목이 남지만, 용품은 거래 이력이 곧 그 물건의 존재 근거이기 때문입니다.

나머지는 게임 거래와 완전히 같습니다 — 같은 거래 모델, 같은 보유 판정, 같은 요약 계산.

---

## 통계에 어떻게 합쳐지나

| 화면 | 게임과 용품 |
|---|---|
| **내 기록 → 거래 탭** | 세그먼트로 **분리**해서 봅니다 |
| **홈 화면 거래 통계 미니카드** | **합산** |
| **인사이트 → 지출 및 컬렉션 통계** | **합산** |

"보드게임에 얼마 쓰나"를 물을 때 슬리브 값을 빼놓을 이유가 없기 때문에
전체 통계에서는 합쳐서 봅니다.
