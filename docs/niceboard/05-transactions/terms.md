# 5.4 금액 용어 사전
{: .no_toc }

화면마다 나오는 금액 이름이 조금씩 다릅니다. 각각이 무엇을 세는지 정리했습니다.

1. TOC
{:toc}

---

## 핵심 용어

| 용어 | 계산 | 어디에 나오나 |
|---|---|---|
| **수집 누적액** | 돈이 나간 거래(구매 + 선주문/펀딩) 금액의 합 | 거래 기록 요약 카드 |
| **방출 회수액** | 방출 거래로 돌려받은 금액의 합 | 거래 기록 요약 카드 |
| **소비액** | 수집 누적액 − 방출 회수액 | 거래 기록 요약, 홈 화면, 인사이트 |
| **세이브** | 소비액이 **음수일 때**의 표시. 판 돈이 산 돈보다 많다는 뜻 | 소비액 자리에 대신 표시 |
| **이번 달 지출** | 이번 달에 돈이 나간 거래의 합 | 홈 화면 거래 통계 |
| **거래 건수** | 구매 + 방출 + 선주문/펀딩 전부의 건수 | 홈 화면 거래 통계 |

소비액은 **"이 취미에 실제로 얼마를 썼나"**를 답하는 숫자입니다.
100만 원어치 사고 30만 원어치 팔았다면 소비액은 70만 원입니다.

---

## 거래 종류 세 가지

| 종류 | 색 | 뜻 | 돈이 나가나 | 보유가 되나 |
|---|---|---|---|---|
| **구매** | 초록 | 샀다 | 예 | 예 |
| **방출** | 주황 | 팔거나 넘겼다 | 아니요 (들어옴) | 아니요 |
| **선주문/펀딩** | 네이비 | 결제했는데 아직 안 왔다 | **예** | **아니요** |

여기서 자주 헷갈리는 지점이 하나 있습니다.

{: .note }
> **지출을 셀 때는 선주문도 포함되지만, 보유를 셀 때는 포함되지 않습니다.**
> 선주문은 "돈은 나갔고 물건은 안 왔다"는 상태이므로 당연한 결과입니다.
> 인사이트의 `거래 내역 요약`이 **구매 N건**과 **선주문/펀딩 N건**을 따로 세는 이유이기도 합니다.

---

## 선주문이 가계부에 잡히는 시점

```
결제일(2월 3일)  ─────────────────▶  수령일(6월 20일)
     │                                    │
   2월 지출에 잡힘                    지출 변화 없음
                                    (보유로만 바뀜)
```

- **결제한 달**의 지출로 잡힙니다
- **수령해도 새 지출이 생기지 않습니다** — 결제일이 그대로 유지되기 때문에 같은 돈이 두 번 세어지지 않습니다
- **선주문을 취소하면** 결제 거래가 삭제되어 그 달의 지출에서 **빠집니다**

---

## 요약 카드의 제목이 바뀔 때

거래 기록 화면의 요약 카드 제목은 기본적으로 **전체 합계**입니다.
게임(또는 용품) 필터를 걸면 **`게임명 합계`**로 바뀌고, 그때는
**그 게임의 전체 거래**를 기준으로 계산합니다 — 다른 필터(기간·경로 등)와 무관합니다.

"이 게임에 그동안 얼마 썼지?"를 요약 카드가 바로 답하도록 만든 예외입니다.

{: .note }
> 그래서 요약 카드의 숫자와 아래 목록의 건수가 다를 수 있습니다.
> 지금 조건에 걸린 결과 수는 요약 카드 아래의 `표시 중 N건 / 전체 M건` 캡션이 알려 줍니다.

## 보유 기간과 관련된 용어

인사이트 탭의 **보유 기간 통계**와 **장롱 지수**에서 쓰는 말입니다.

| 용어 | 뜻 |
|---|---|
| **완결 거래(사이클)** | 구매 → 방출까지 끝난 한 쌍 |
| **평균 보유** | 현재 보유 중인 게임들을 얼마나 오래 갖고 있는지의 평균 |
| **최장 보유** | 가장 오래 갖고 있는 게임 |
| **장롱 지수** | 오래 보유했는데 플레이가 뜸한 정도 (연환산 플레이 횟수 기준) |

보유 기간의 시작일은 **수령일이 있으면 수령일, 없으면 거래일**입니다.
배송을 기다린 기간을 보유로 세지 않기 위해서입니다.

자세한 내용은 [6.3 지표 사전](../../06-insights/metrics/)에 있습니다.

## 상태와 방식

거래를 입력할 때 고르는 두 가지 분류입니다.

| 항목 | 값 | 쓰이는 곳 |
|---|---|---|
| **상태** | 신규 / 중고 | 거래 기록의 신규·중고 지출 비율 도넛 |
| **방식** | 온라인 / 오프라인 | 추가 필터 |
| **경로** | 자유 입력 또는 목록 선택 | 채널별 지출 순위 차트 |
