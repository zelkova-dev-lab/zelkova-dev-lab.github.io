## 어디서 등록하나

| 경로 | 특징 |
|---|---|
| **게임 상세 → 거래 이력 카드 → 거래 추가** | 가장 일반적. 한 시트에서 여러 게임을 한꺼번에 넣을 수도 있습니다 |
| **내 기록 → 거래 탭 → 오른쪽 위 +** | 게임을 먼저 검색해서 고른 뒤 입력합니다 |
| **컬렉션 → 보유 중 탭 → 🧾 아이콘 → +** | 위와 같은 화면입니다 |

---

## 입력 항목

`*` 표시는 필수입니다.

| 항목 | 설명 |
|---|---|
| **거래 종류 \*** | **구매 / 방출 / 선주문/펀딩** 중 하나 |
| **거래 게임 목록 \*** | **게임 추가**로 여러 게임을 넣을 수 있습니다. 같은 조건의 거래를 한 번에 기록할 때 편합니다. 검색 시트는 두 글자부터 자동으로 찾고, 엔터를 누르면 BGG까지 넓힙니다 → [공통 조작](../../01-getting-started/screen-map/#게임-검색은-두-글자부터-자동입니다) |
| **거래일 \*** | 돈이 오간 날. 선주문일 때는 **결제일** 역할 |
| **예상 수령일 \*** | **선주문/펀딩일 때만, 그리고 필수.** 미래 날짜를 넣을 수 있습니다 |
| **상태** | **신규 / 중고** — 돈이 나가는 거래(구매·선주문)에만 나옵니다 |
| **구매 경로 / 방출 경로** | 어디서 사고 팔았는지 ([아래 목록](#경로-선택지)) |
| **구매 방식 / 방출 방식** | **온라인 / 오프라인** |
| **판매자 / 구매자** | 거래 상대. 친구 목록에서 고를 수 있습니다 |
| **가격 (원)** | 천 단위 콤마가 자동으로 붙습니다 |
| **메모** | 자유 입력 |

{: .note }
> **가격을 0으로 넣어도 됩니다.** 선물로 받았거나 교환한 경우처럼 지출이 없었던 거래도
> 이력으로 남겨 두면 보유 기간과 플레이 통계가 정확해집니다.
> (입력을 비우면 *"가격을 입력해 주세요. (지출이 없었다면 0 입력)"* 안내가 나옵니다.)

### 경로 선택지
{: #경로-선택지 }

중고·방출 거래에서는 목록에서 고르고, 신규 구매에서는 자유롭게 입력합니다.

`보드라이프` · `보드엠` · `보드피아` · `보드게임몰` · `아스모디/만두` ·
`당근마켓` · `번개장터` · `중고나라` · `기타 - 직접 입력` · `정보 없음 (알수없음)`

---

## 저장하면 무슨 일이 일어나나

거래를 저장하면 **보유 상태가 자동으로 정해집니다.** 보유 스위치를 따로 만질 필요가 없습니다.

| 등록한 거래 | 결과 |
|---|---|
| **구매** | 보유 중으로 들어감. 위시리스트에 있었다면 자동으로 빠짐 |
| **방출** | 보유 중에서 빠짐 |
| **선주문/펀딩** | 선주문/펀딩 탭으로 들어감. 지출에는 잡히지만 보유로는 안 셈 |

가장 **최근 거래**가 현재 상태를 결정합니다.
사고 → 팔고 → 다시 산 게임은 마지막 구매 때문에 보유 중이 됩니다.

---

## 거래 고치기 · 지우기

게임 상세의 **거래 이력** 카드에서

- **탭** → 편집 시트
- **길게 누르기** → 삭제 확인

거래 이력 카드는 2건 이하면 자동으로 펼쳐지고, 3건 이상이면 접혀 있습니다.
헤더에 건수와 손익 합계가 함께 표시됩니다.

{: .note }
> **거래를 전부 지워도 보유 표시와 게임 항목은 남습니다.**
> 가계부를 정리하는 것과 게임을 처분하는 것은 다른 일이기 때문입니다.
> 게임을 목록에서 빼려면 컬렉션에서 휴지통을 누르세요.

---

## 작성하다 나갈 때

거래 시트에서 뭔가 입력한 뒤 뒤로 가거나 바깥을 탭하면
**작성 취소** 확인 창이 뜹니다 (*"저장하지 않고 나가면 작성 중인 내용이 사라집니다. 나가시겠습니까?"*).
아무것도 입력하지 않았다면 바로 닫힙니다.
