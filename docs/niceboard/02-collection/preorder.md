# 2.5 선주문/펀딩 완전 가이드
{: .no_toc }

킥스타터 펀딩이나 예약 판매처럼 **돈은 나갔는데 물건은 아직 안 온** 상태를 위한 기능입니다.

1. TOC
{:toc}

---

## 왜 따로 있나

선주문한 게임은 어디에도 딱 맞지 않습니다.

- **보유 중**에 넣으면 → 없는 게임을 갖고 있다고 세게 됩니다
- **위시리스트**에 두면 → 이미 결제한 돈이 가계부에서 빠집니다

그래서 **선주문/펀딩**은 "지출은 잡히되 보유로는 안 세는" 별도 상태입니다.

| | 보유로 세나 | 지출로 잡히나 |
|---|---|---|
| 위시리스트 | 아니요 | 아니요 |
| **선주문/펀딩** | **아니요** | **예** |
| 보유 중 | 예 | 예 |

---

## 선주문은 스위치가 아닙니다
{: .d-inline-block }

중요
{: .label .label-red }

보유·위시리스트는 아이콘을 눌러 켜고 끄지만, **선주문/펀딩은 거래에서 파생되는 상태**입니다.
"결제했다"는 사실이 있어야 성립하기 때문에 켜는 스위치가 없습니다.

그래서 등록 · 수령 · 취소가 각각 다른 곳에 있습니다.

| 하려는 일 | 어디서 |
|---|---|
| **등록** | 게임 상세 → 거래 이력 카드 → **거래 추가** → **선주문/펀딩** |
| **수령 완료** | 컬렉션 **선주문/펀딩** 탭 → 📦 아이콘 |
| **취소** | 컬렉션 **선주문/펀딩** 탭 → 🗑 아이콘 |

---

## 1. 등록하기

1. 게임 상세 화면으로 들어갑니다
2. 아래로 내려 **거래 이력** 카드의 **거래 추가**를 누릅니다
3. 거래 종류에서 **선주문/펀딩**을 고릅니다
4. 입력합니다

| 항목 | 설명 |
|---|---|
| **결제일** | 필수. 돈이 나간 날. 가계부에서 이 달의 지출로 잡힙니다 |
| **예상 수령일** | **필수.** 미래 날짜를 넣을 수 있고 나중에 수정할 수 있습니다 |
| 가격 | 결제 금액 |
| 상태 | 신규 / 중고 |
| 경로 · 방식 · 메모 | 선택 |

저장하면 게임이 **선주문/펀딩** 탭으로 들어가고, 위시리스트에 있었다면 자동으로 빠집니다.

{: .note }
> 예상 수령일이 필수인 이유는 **'언제 오는지'가 선주문의 핵심 정보**이기 때문입니다.
> 아직 모르면 대략적인 날짜를 넣고 나중에 거래를 편집해 고치세요.

---

## 2. 물건이 도착했을 때 — 수령 완료

**컬렉션 → 선주문/펀딩 탭**에서 해당 게임의 **📦 아이콘**을 누릅니다.

1. 수령일을 고르는 달력이 뜹니다 (기본값 오늘)
2. **수령 완료**를 누르면 게임이 **보유 중**으로 옮겨갑니다
3. `— 보유 중으로 옮겼습니다.` 메시지가 뜹니다

**결제일은 그대로 유지됩니다.** 결제한 달의 지출은 그대로 남고,
새 지출이 추가되지 않으므로 **같은 돈이 두 번 잡히는 일이 없습니다.**

수령 완료는 다른 두 곳에서도 할 수 있습니다.

- 게임 상세의 **주황색 선주문 상태 칩**을 탭
- 게임 상세 **거래 이력** 카드에서 그 거래 행의 **수령** 버튼

수령한 뒤에도 거래에는 `선주문/펀딩` 뱃지와 **수령일**이 계속 남아,
"이건 펀딩으로 산 거였지"를 나중에도 알 수 있습니다.

### 수령을 잘못 눌렀다면

거래 이력에서 그 거래를 **탭해서 편집**하면 선주문/펀딩 토글이 보입니다.
다시 켜서 저장하면 수령 전 상태로 돌아갑니다 (수령일만 지워지고 결제일은 유지).
수령일을 잘못 넣은 경우에도 같은 화면에서 고칠 수 있습니다.

---

## 3. 취소하기

펀딩이 무산됐거나 주문을 물렀을 때입니다.
**컬렉션 → 선주문/펀딩 탭**에서 **🗑 아이콘**을 누릅니다.

{: .warning }
> **선주문/펀딩 취소**는 결제 거래를 **함께 삭제**합니다.
> 확인 창에 `'게임명'의 결제 거래 N건을 삭제하고 목록에서 제거합니다. 가계부 지출에서도 빠집니다.`
> 라고 나오며, **가계부의 지출 금액이 줄어듭니다.** 되돌릴 수 없습니다.

다른 탭의 휴지통은 확인 없이 바로 지워지지만 선주문만 확인을 받는 이유가 이것입니다 — 지워지는 것의 무게가 다릅니다.

환불이 아니라 **그냥 목록에서 치우고 싶은 것뿐**이라면, 취소하지 말고
수령 완료로 처리한 뒤 보유 중에서 방출 거래를 넣는 편이 이력이 정확하게 남습니다.

## 다른 화면에서의 선주문

| 화면 | 어떻게 보이나 |
|---|---|
| **게임 상세** | 이름 옆에 주황 칩 `선주문 · 수령 예정 Y.M.D` 또는 `선주문/펀딩 배송 대기`. 탭하면 수령 완료 |
| **인사이트 탭** | `선주문/펀딩 대기` 카드 — 대기 건수와 묶인 금액, 수령 예정순 목록. **기간 필터를 따르지 않고 현재 상태 기준**입니다 |
| **거래 기록** | 종류 칩에 `선주문/펀딩`이 따로 있고, 요약에도 `선주문/펀딩 N건`이 별도 표시됩니다 |
| **홈 화면** | 이번 달 지출에 결제 금액이 포함됩니다 |

---

## 선주문 중에는 막히는 동작

미수령 선주문이 있는 동안에는 앱이 다음을 인터셉트합니다.

| 하려던 것 | 실제 동작 |
|---|---|
| 보유 토글 켜기 | 맨몸으로 켜지지 않고 **수령 완료 절차**로 넘어갑니다 |
| 위시리스트 켜기 | 안내 메시지와 함께 막힙니다 — *"선주문/펀딩 진행 중인 게임입니다. 취소는 컬렉션 선주문 탭에서 할 수 있어요."* |
| 즐겨찾기 | 자유롭게 켜고 끌 수 있습니다 |

"보유에 넣기"의 진짜 의미가 **수령 완료**이기 때문입니다.
표시만 뒤집으면 아직 안 받은 결제 거래와 앞뒤가 안 맞게 됩니다.

---

## BGG 동기화·백업과의 관계

- **BGG 동기화**는 미수령 선주문 게임을 건드리지 않습니다. 수령 처리는 사용자가 앱에서 직접 하도록 남겨 둡니다
- **BG Stats 호환 백업**으로 내보내면 BG Stats의 "Preordered" 그룹으로 들어가고, 가져올 때도 선주문으로 복원됩니다
- **나이스보드 전체 백업**은 결제일·예상 수령일까지 그대로 왕복합니다
