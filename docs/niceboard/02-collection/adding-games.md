{: .note }
> **표시만 켜는 것과 거래를 등록하는 것은 다릅니다.**
> 표시만 켜면 "갖고 있다"는 사실만 남고, 거래를 등록하면 **가계부와 통계**(지출, 보유 기간, 장롱 지수)까지 함께 채워집니다.
> 나중에 언제든 거래를 추가할 수 있으니 처음엔 가볍게 담아도 괜찮습니다.

## 1. 검색 결과에서 바로 담기
{: #1-검색-결과에서-바로-담기 }

**검색** 화면에서 게임을 찾으면 각 결과 카드에 토글 버튼이 붙어 있습니다.

| 버튼 | 하는 일 |
|---|---|
| **보유 게임 추가 / 보유 취소** | 보유 중 목록에 넣거나 뺍니다 |
| **위시리스트 추가 / 취소** | 위시리스트에 넣거나 뺍니다 |
| **즐겨찾기에 추가 / 제거** | 즐겨찾기에 넣거나 뺍니다 |

누를 때마다 화면 아래에 확인 메시지가 뜹니다.

{: .note }
> 검색 결과에는 **선주문/펀딩 항목이 없습니다.** 선주문은 결제 정보가 있어야 성립하므로
> 반드시 거래로 등록합니다 → [2.5 선주문/펀딩 완전 가이드](../preorder/)

## 2. 게임 상세 화면에서
{: #2-게임-상세-화면에서 }

게임 상세로 들어가면 게임 이름 옆에 토글 세 개가 있습니다.

| 아이콘 | 뜻 |
|---|---|
| 북마크 | 즐겨찾기 |
| 하트 | 위시리스트 |
| 라이브러리 | 보유 |

선주문이 진행 중인 게임에서는 보유 토글 대신 **주황색 선주문 상태 칩**이 보이고,
그 칩을 누르면 곧바로 **수령 완료** 절차로 들어갑니다.

---

## 3. 거래를 등록해서 담기 (권장)
{: #3-거래를-등록해서-담기-권장 }

게임 상세 화면을 아래로 내리면 **거래 이력** 카드가 있습니다. 여기서 **거래 추가**를 누르세요.

1. 거래 종류를 고릅니다 — **구매 / 방출 / 선주문/펀딩**
2. 날짜, 가격, 구입처, 상태(신규·중고) 등을 입력합니다
3. 저장하면 **보유 상태가 자동으로 결정됩니다**

구매 거래를 넣으면 별도로 보유 토글을 켜지 않아도 **보유 중**이 됩니다.
입력 항목의 자세한 설명은 [5.1 게임 거래 등록](../../05-transactions/game-transactions/)에 있습니다.

## 4. BGG에서 한꺼번에 가져오기
{: #4-bgg에서-한꺼번에-가져오기 }

BoardGameGeek 계정에 컬렉션이 이미 있다면 통째로 가져올 수 있습니다.

**내 정보 → 데이터 → BGG 컬렉션 동기화**

BGG 아이디를 넣고 가져올 항목(보유 게임 · 위시리스트 · 이전 보유 → 처분 이력 · 플레이 기록 · 구매가·일자)을 고르면 됩니다.
자세한 절차와 주의점은 [11.1 BGG 컬렉션 동기화](../../11-data-settings/bgg-sync/)를 보세요.

## 목록에 없는 게임이라면

나이스보드의 게임 정보는 BGG 카탈로그에서 옵니다. 검색해도 안 나오는 게임은
BGG에 아직 등록되지 않았거나 이름이 달리 등록돼 있을 수 있습니다.
**원어 이름(영문)으로 다시 검색**해 보세요 — 한글 이름은 정식 발매명이 있는 게임에만 붙습니다
([3.3 게임 이름과 한글명 제안](../../03-games/korean-names/)).
