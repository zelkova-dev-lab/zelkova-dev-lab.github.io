# 2. 컬렉션 관리
{: .no_toc }

**컬렉션** 탭은 내가 가진 게임과 갖고 싶은 게임을 관리하는 곳입니다.
탭이 네 개인 이유는 게임이 손에 들어오는 흐름을 그대로 따라가기 때문입니다.

> **즐겨찾기** → **위시리스트**(갖고 싶다) → **선주문/펀딩**(결제했다) → **보유 중**(갖고 있다)

| 절 | 내용 |
|---|---|
| [2.1 네 개의 탭 이해하기](tabs/) | 각 탭의 의미, 건수 표시, 빈 목록에서 할 일 |
| [2.2 게임 담기](adding-games/) | 검색에서 · 게임 상세에서 · BGG 동기화로 |
| [2.3 정렬과 필터](sorting/) | 정렬 기준 6종과 탭별 기본값 |
| [2.4 본판과 확장](expansions/) | 확장이 본판 카드에 묶여 보이는 규칙 |
| [2.5 선주문/펀딩 완전 가이드](preorder/) | 등록 · 수령 · 취소와 가계부 반영 |

{: .warning }
> **선주문/펀딩은 켜고 끄는 스위치가 아닙니다.** 거래에서 파생되는 상태라서
> 등록 · 수령 · 취소의 경로가 각각 다릅니다. [2.5](preorder/)를 꼭 읽어 주세요.
