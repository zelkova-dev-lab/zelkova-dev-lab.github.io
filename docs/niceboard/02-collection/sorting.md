## 정렬 바꾸기

탭 바로 아래 **정렬 메뉴**에서 기준을 고릅니다.

| 기준 | 무엇으로 줄 세우나 | 어느 탭에서 |
|---|---|---|
| **추가순** | 목록에 담은 날짜 | 모든 탭 |
| **거래순** | 가장 최근 거래일 | **보유 중** 탭만 |
| **수령 예정순** | 예상 수령일 | **선주문/펀딩** 탭만 |
| **이름순** | 화면에 보이는 이름 (한글명 우선) | 모든 탭 |
| **웨이트순** | BGG 난이도(weight) | 모든 탭 |
| **평점순** | BGG 평점 | 모든 탭 |

**같은 기준을 다시 누르면 오름차순 ↔ 내림차순이 뒤집힙니다.** 메뉴의 화살표가 현재 방향을 알려 줍니다.

---

## 탭마다 기본 정렬이 다릅니다

| 탭 | 기본 정렬 |
|---|---|
| 보유 중 | **거래순** (최근에 산 것부터) |
| 선주문/펀딩 | **수령 예정순** 오름차순 (곧 올 것부터) |
| 위시리스트 · 즐겨찾기 | **추가순** |

그 탭에서 가장 궁금한 순서를 기본값으로 잡아 둔 것입니다.

{: .note }
> 정렬 설정은 **탭마다 따로 저장되고 앱을 껐다 켜도 유지됩니다.**
> 보유 중을 이름순으로 바꿔 놓아도 위시리스트는 추가순 그대로입니다.

## 값이 없는 항목은 어디로 가나

거래 이력이 없어서 거래일을 모르거나, 카탈로그 정보가 없어 평점·난이도를 모르는 항목은
**오름차순이든 내림차순이든 항상 뒤쪽**으로 갑니다. 빈 값이 맨 앞을 차지해 목록을 가리는 일을 막기 위해서입니다.

이름순 · 웨이트순 · 평점순은 BGG 카탈로그 정보가 필요합니다.
화면에 처음 들어가면 앱이 정보를 받아오는 동안 일부 항목이 잠깐 뒤에 있다가 **정렬이 다시 맞춰집니다.**

## 게임 찾기

컬렉션 안에는 검색창이 따로 없습니다. 특정 게임을 찾을 때는

- 오른쪽 위 **돋보기**로 게임 검색에 들어가 **보유 게임만 보기** 필터를 켜거나
- **이름순** 정렬로 바꿔 훑어보세요

게임 검색의 필터는 보유 여부 · 인원수 · 플레이 시간 · 평점 · 난이도 · 출판 연도 · 장르
