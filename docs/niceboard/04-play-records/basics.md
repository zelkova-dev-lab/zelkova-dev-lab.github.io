## 기록 시작하기

| 어디서 | 어떻게 |
|---|---|
| **홈 화면** | **새 플레이 기록** 버튼 → 게임 고르기 |
| **게임 상세** | **플레이 기록 추가** 버튼 |
| **내 기록 → 플레이 탭** | 오른쪽 위 **+** |

홈에서 시작하면 **기록할 게임 선택** 화면이 나옵니다.
여기 위쪽의 **바로 기록 / 라이브 세션** 토글이 중요합니다.

- **바로 기록** — 게임을 고르면 결과 입력 화면으로 갑니다
- **라이브 세션** — 게임을 고르면 플레이 중에 쓰는 도구 화면으로 갑니다 ([4.6](../live-session/))

이 토글은 **최근 플레이 카드·보유 게임 칩뿐 아니라, 검색 화면에서 고른 게임에도 똑같이 적용**됩니다
(검색 결과·BGG Top 50·인기 급상승·즐겨찾기 목록 전부 해당).
라이브 세션으로 두면 검색 버튼도 **다른 게임으로 라이브 세션**으로 바뀝니다.

이 선택은 다음에도 유지됩니다.

### 게임을 고르는 세 가지 방법

토글 아래로 이렇게 이어집니다.

| 순서 | 무엇 | 설명 |
|---|---|---|
| 1 | **최근 플레이** | 마지막으로 한 게임 8개가 가로 카드로. 며칠 전인지 함께 표시됩니다 |
| 2 | **게임 검색해서 기록하기** | 보유 목록에 없는 게임, 남의 집에서 한 게임을 찾을 때 |
| 3 | **보유 게임** | 가지고 있는 게임 칩 목록 (본판만) |

**보유 게임** 목록은 **즐겨찾기(북마크) 게임이 맨 위**로 오고, 그 다음이 가나다순입니다.
즐겨찾기는 위쪽 최근 플레이 카드에 이미 나와 있어도 이 목록에 그대로 남습니다 —
즐겨찾기해 둔 게임은 어디서든 먼저 보이는 편이 낫기 때문입니다.

**확장은 이 목록에 나오지 않습니다.** 나이스보드에서 한 판의 주인공은 본판이고,
그날 쓴 확장은 기록 안의 **확장** 칸에 붙이는 방식이기 때문입니다.
확장을 따로 골라 기록하면 같은 게임의 판수가 본판과 확장으로 쪼개져
게임별 통계와 챌린지가 어긋납니다.

{: .note }
> 확장만으로 플레이할 수 있는 게임이거나, 예전부터 확장으로 기록해 왔다면
> **게임 검색해서 기록하기**로 그 확장을 찾아 고르면 됩니다. 검색에는 제한이 없고,
> 이미 확장으로 남긴 기록은 **최근 플레이** 카드에도 그대로 나옵니다.

보유 게임이 20개를 넘으면 20개까지만 먼저 보여 주고,
목록 아래 **나머지 N개 더 보기**로 전부 펼칠 수 있습니다.

## 최소한으로 필요한 것

기록을 남기는 데 꼭 필요한 건 **날짜와 참가자**뿐입니다. 나머지는 전부 선택입니다.

참가자는 **나** 한 명으로 시작합니다.
**인원 추가**로 함께한 사람을 넣고 승자를 표시한 뒤 저장하면 온전한 기록이 됩니다.

늘 같은 사람들과 한다면 **기본 모임**을 지정해 두세요 —
기록 화면에 들어가는 순간 그 멤버가 참가자로 채워져 있습니다
([4.2 참가자와 역할](../participants/#기본-모임)).

{: .note }
> 비워 두면 이렇게 저장됩니다 — 장소는 `미지정`, 승자는 `없음`.
> 나중에 언제든 기록을 편집해 채울 수 있습니다.

## 화면 순서

```
이전 기록 참고          ← 지난 판 요약 + 빠른 복사
날짜
장소
플레이 방식             ← 항상
확장팩                  ← 이 게임에 쓴 이력이 있을 때만
─────────────────
기록 템플릿             ← 점수 시트 고르기
게임 공통               ← 템플릿에 판 공통 항목이 있을 때만
참가자 및 점수
─────────────────
추가 기록 (스위치)      ← 켜면 플레이 시간·한줄평 등이 나옵니다
```

## 날짜와 장소

- **날짜** — 탭하면 달력이 뜹니다. 기본값은 오늘
- **장소** — 직접 입력하거나, 등록해 둔 장소를 **칩으로 탭**해 채웁니다

등록되지 않은 장소 이름을 입력하면 오른쪽 끝에 **장소로 등록** 아이콘이 나타납니다.
누르면 다음부터 칩으로 바로 고를 수 있습니다 → [9.4 장소](../../09-friends-groups/places/)

## 참가자와 승패

**참가자 및 점수** 섹션에서 다룹니다. 자세한 내용은 [4.2 참가자와 역할](../participants/)에 있고, 여기서는 승패만 짚습니다.

| 점수 유형 | 승자를 어떻게 정하나 |
|---|---|
| 점수가 있는 유형 | **점수로 승리(달성) 자동 판정** 스위치를 켜면 점수가 가장 높은(또는 낮은) 사람이 자동으로 승자가 됩니다 |
| 승/패 유형 | 참가자별로 직접 승패를 표시합니다 |
| 협력 게임 | **팀 미션 달성 (승리)** 체크박스 하나로 전원의 승패가 정해집니다 |
| 순위 기록 | 참가자마다 `N등`을 고릅니다 |

첫 번째 참가자에는 **(나)** 표시가 붙습니다. 이 사람이 **나**이며,
승률 · 배지 · 챌린지의 "내 성적"은 전부 이 자리를 기준으로 계산됩니다.

## 선 플레이어

참가자 행의 **선** 체크박스로 누가 먼저 시작했는지 표시합니다.
**참가자 및 점수** 헤더의 🎲 버튼(**선 플레이어 랜덤 뽑기**)을 누르면 앱이 무작위로 뽑아 줍니다.

---

## 추가 기록

**추가 기록** 스위치를 켜면 항목이 더 나옵니다.
"상황 설정 → 결과 → 회고" 순서로 놓여 있습니다.

- 플레이 방식 · 확장팩 (위로 승격되지 않은 게임만)
- **플레이 시간** — 스톱워치 또는 직접 입력
- **한줄평 / 메모**

자세한 내용은 [4.4 플레이 방식 · 확장팩 · 시간](../details/)에 있습니다.

## 저장하기

저장 버튼은 두 군데 있습니다.

- 화면 맨 아래 **저장** 버튼
- 오른쪽 위 **💾 아이콘** — 폼이 길어져도 스크롤 없이 바로 저장할 수 있습니다

저장하면 `플레이 기록이 저장되었습니다.`(수정이면 `기록이 수정되었습니다.`) 메시지가 뜹니다.

{: .warning }
> **작성 중에 뒤로 가면 확인 창이 뜹니다** — *"저장하지 않고 나가면 작성 중인 내용이 사라집니다. 나가시겠습니까?"*
> **계속 작성**을 누르면 돌아가 이어서 쓸 수 있습니다.
