# 4.5 이전 기록 빠른 복사
{: .no_toc }

늘 같은 사람들과 같은 템플릿으로 논다면, 매번 처음부터 입력할 필요가 없습니다.

## 이전 기록 참고 카드

기록 입력 화면 맨 위에 있습니다. 두 부분으로 되어 있습니다.

### 위쪽 — 이 게임의 요약

| 항목 | 뜻 |
|---|---|
| **총 플레이** | 이 게임을 몇 판 했나 |
| **내 승률** | 내가 이긴 비율 |
| **최근 플레이** | 마지막으로 한 날 |
| **평균 플레이 시간** | 한 판에 보통 얼마나 걸리나 |

### 아래쪽 — 최근 플레이 목록

*"최근 플레이 (탭하면 위 조건으로 즉시 복사)"*

최근 2건이 나오고, **탭하면 체크해 둔 항목이 폼에 즉시 채워집니다.**

---

## 무엇을 복사할지 고르기

**이전 기록 불러오기 옵션**의 체크박스 다섯 개로 정합니다.

| 옵션 | 복사되는 것 |
|---|---|
| **날짜** | 그 판의 날짜 |
| **장소** | 장소 텍스트 |
| **참가자·역할** | 참가자 이름과 각자의 역할 목록 |
| **방식·확장** | 플레이 방식과 확장팩 |
| **템플릿** | 점수 시트 템플릿 + 게임 공통 항목 값 |

**방식·확장** 옵션은 이 게임에 그런 이력이 있을 때만 나타납니다.

복사가 끝나면 `이전 기록 정보가 적용되었습니다.` 메시지가 뜹니다.

---

## 안 지워지는 규칙

{: .note }
> **원본에 있는 값만 덮어씁니다.**
> 플레이 방식만 있고 확장은 없는 기록을 복사해도, 이미 골라 둔 확장팩은 **지워지지 않습니다.**
> 템플릿이 없는 기록을 복사해도 지금 고른 템플릿이 유지됩니다.

체크한 항목이라도 원본에 값이 없으면 그냥 건너뛴다고 생각하면 됩니다.

---

## 점수는 복사되지 않습니다

참가자 **이름과 역할**은 오지만 **점수는 오지 않습니다.**
매 판 달라지는 값이라 복사할 이유가 없기 때문입니다.

---

## 라이브 세션에도 같은 기능이 있습니다
{: #라이브-세션에도-같은-기능이-있습니다 }

라이브 세션 설정 시트는 그 게임의 **최근 기록에서 참가자·템플릿을 미리 채워** 둡니다.
참가자 영역에 `최근 기록 기준` 캡션이 붙어 있으면 프리필이 적용된 것입니다.

- 참가자 이름은 **실제 이름이 남아 있는 경우에만** 채워집니다
- 참가자가 한 명이면 **솔로 스위치도 자동으로 켜집니다**
- 템플릿은 최근 기록 → 게임 프리셋 → 기본 순서로 고릅니다

{: .note }
> 프리필로 들어온 참가자는 **친구 계정 연결이 풀린 상태**로 시작합니다.
> 칩을 탭해 다시 연결할 수 있습니다. 대신 **모임 불러오기**로 넣으면 연결이 유지됩니다.
