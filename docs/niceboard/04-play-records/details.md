# 4.4 플레이 방식 · 확장팩 · 시간
{: .no_toc }

같은 게임이라도 어떤 맵으로, 어떤 확장을 넣고 했느냐에 따라 다른 게임이 됩니다.
이 정보를 남겨 두면 통계가 훨씬 쓸모 있어집니다.

1. TOC
{:toc}

---

## 플레이 방식

**맵 · 시나리오 · 모드 · 룰 변형** 같은 "이번 판을 어떻게 했나"를 기록합니다.
**판당 하나**만 고를 수 있습니다.

| 예 | 어떤 게임에서 |
|---|---|
| `유럽 맵` | 티켓 투 라이드 |
| `시나리오 3 - 검은 협곡` | 글룸헤이븐 |
| `고급 룰` | 아그리콜라 |

라벨 옆 **(i)** 아이콘을 누르면 설명이 나옵니다 — 맵/보드, 룰 변형, 시나리오/모드의 예시와
"판당 하나만 기록되며, 나중에 게임 통계에서 '유럽 맵으로 12판' 처럼 방식별로 묶여 보입니다"라는 안내입니다.

입력은 [값 피커](../participants/#값-피커-사용법)로 합니다.
전에 쓴 방식이 빈도순으로 나오고, 새 값은 직접 입력합니다.

### 어디에 나타나나

- **처음 쓰는 게임** — **추가 기록** 스위치를 켜야 보입니다
- **한 번이라도 쓴 게임** — 기본 화면의 **장소 아래**로 올라옵니다

한 번 쓰기 시작한 게임에서는 매번 스위치를 켤 필요가 없도록 만든 동작입니다.
편집 중인 기록에 방식이 들어 있는 경우에도 마찬가지로 올라옵니다.

---

## 확장팩

이번 판에 넣은 확장을 고릅니다. **여러 개** 고를 수 있습니다.

- 앱이 아는 확장은 **칩 목록**으로 나옵니다
- 목록에 없으면 **목록에 없는 확장팩 직접 입력**
- 확장이 10개를 넘으면 8개만 보이고 **+N개 더 / 접기** 버튼이 나옵니다. 접혀 있어도 **고른 확장은 위쪽 선택 칩 줄에 항상 보입니다**

플레이 방식과 마찬가지로, 이 게임에 확장을 쓴 이력이 있으면 기본 화면으로 올라옵니다.

{: .note }
> 여기서 고르는 확장은 **이번 판에 사용한 확장**입니다.
> 컬렉션에서 확장을 보유하고 있는 것과는 별개이며,
> 게임 통계의 **확장팩별 승률** 카드에 쓰입니다.

## 플레이 시간

**추가 기록**을 켜면 나옵니다.

| 방법 | 어떻게 |
|---|---|
| **스톱워치** | **시작 / 일시정지**로 재고, **초기화**로 리셋 |
| **직접 입력** | **시간 직접 입력** — *"숫자를 입력하면 hh:mm 으로 자동 변환돼요 (예: 130 → 01:30)"* |

기록된 시간은 게임 통계의 **총 플레이 시간**과 **평균 플레이 시간**에 쓰입니다.

{: .note }
> 라이브 세션으로 플레이하면 시간이 **자동으로 채워집니다** → [4.6 라이브 세션](../live-session/)

## 한줄평 / 메모

*"이 게임 어땠나요? 기억에 남는 순간을 남겨보세요."*

기록 상세 시트와 **오늘의 플레이 카드** 공유 이미지에 함께 나옵니다.

라이브 세션에서 넘어온 기록이고 한줄평이 비어 있으면,
앱이 플레이어별 턴 시간과 카운터 값을 요약해 **자동으로 채워 줍니다.**

```
플레이어별 시간 — 나 12:30, 민수 09:44
카운터 — 나: 생명 3, 자원 5 / 민수: 생명 1
```

지우거나 고쳐도 됩니다.

## 이 정보들이 만드는 통계

게임 통계 화면([6.2](../../06-insights/game-stats/))에서 이렇게 쓰입니다.

| 입력한 것 | 만들어지는 카드 |
|---|---|
| 플레이 방식 | **플레이 방식별 승률** |
| 확장팩 | **확장팩별 승률** |
| 역할 | **역할별 성적**, **역할 조합** |
| 텍스트 항목 | **{항목}별 성적** |
| 게임 공통 항목 | **{항목}별 승률** |
| 플레이 시간 | 총·평균 플레이 시간 |

그리고 이 모두가 게임 통계의 **고급 필터** 조건이 됩니다.
