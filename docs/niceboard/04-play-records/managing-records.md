# 4.7 기록 목록 관리
{: .no_toc }

**내 기록 → 플레이** 탭에 모든 플레이 기록이 모입니다.

1. TOC
{:toc}

---

## 화면 구성

```
요약 카드 (총 플레이 / 승률 / 게임)
[전체][최근 1년][최근 30일][최근 7일][직접 선택]
[전체][내가 이김][내가 짐]
[🎲 게임 선택]
표시 중 N건 / 전체 M건              [선택]
────────────────────────────────
기록 카드 목록
```

요약 카드의 **총 플레이**는 **지금 필터가 걸린 결과** 기준입니다.
전체 대비가 궁금하면 아래 `표시 중 N건 / 전체 M건` 캡션을 보세요.

---

## 걸러 보기

| 필터 | 값 |
|---|---|
| **기간** | 전체 / 최근 1년 / 최근 30일 / 최근 7일 |
| **게임** | **게임 선택** 칩 → 시트에서 고름. 시트 안에서 이름 검색 가능 (띄어쓰기를 빼거나 이름 중간부터, 초성으로 쳐도 됩니다) |
| **결과** | 전체 / 내가 이김 / 내가 짐 |

{: .note }
> 게임 선택 시트는 **기록에 저장된 이름과 카탈로그의 최신 한글명 둘 다** 검색합니다.
> 영어 이름으로 기록해 둔 게임도 한글로 찾을 수 있습니다.

홈 화면의 **플레이 히트맵**에서 특정 날짜를 탭해 들어오면 기간이 `직접 선택`으로 잡힙니다.

---

## 기록 하나 다루기

| 조작 | 결과 |
|---|---|
| **카드 탭** | 기록 상세 시트 |
| **썸네일 탭** | 게임 상세 화면 (한 게임만 보는 목록에서는 기록 상세 시트) |
| **카드 오른쪽 위 ↗** | 오늘의 플레이 카드로 바로 공유 |
| **길게 누르기** | 다중 선택 모드 진입 |

### 기록 상세 시트

날짜 · 장소 · 경과 시간 · 플레이 방식이 위쪽에 나오고,
**결과** 섹션에 참가자별 승패 · 점수 · 역할 · 선 표시가 들어갑니다.
사용한 확장팩과 게임 공통 기록도 함께 보입니다.

아래쪽 버튼은 **삭제** / **편집**입니다.

{: .note }
> **모임 만들기** — 결과 섹션 헤더의 버튼입니다 (나 외에 참가자가 있을 때만).
> 이 판의 참가자들로 모임을 바로 만듭니다. 친구로 등록되지 않은 이름은 **친구로 자동 생성**되어 들어갑니다.
> "나"는 항상 포함되므로 따로 넣지 않습니다.

---

## 여러 건 한꺼번에 지우기

1. 건수 캡션 오른쪽의 **선택** 버튼, 또는 카드를 **길게 누르기**
2. 지울 기록을 탭해서 고릅니다
3. 화면 아래 바에서 **삭제**

확인 창: *"선택한 N건의 플레이 기록을 삭제할까요? 이 작업은 되돌릴 수 없어요."*

{: .note }
> 마지막 하나를 선택 해제하면 선택 모드가 자동으로 끝납니다.
> 필터를 바꿔서 화면에서 사라진 기록은 선택에서 자동으로 빠집니다 — **안 보이는 기록이 지워지지 않도록** 하기 위해서입니다.

## 다른 곳에서 열리는 기록 목록

같은 화면이 여러 맥락으로 열립니다. 제목이 다릅니다.

| 제목 | 어디서 들어왔나 | 범위 |
|---|---|---|
| **내 기록 → 플레이** 탭 | 메인 탭 | 전체 |
| **내 플레이 기록** | 홈 화면 **내 플레이 보기** | 전체 |
| **{게임명} 기록** | 게임 상세 · 게임 통계의 **기록 보기** | 그 게임만 |
| **미보유 플레이** | 홈 화면 **미보유 플레이** 미니카드 | 플레이 당시 안 갖고 있던 판만 |

{: .note }
> 어느 맥락으로 열든 **카드 모양은 같습니다.**
> 한 게임만 보는 목록에서는 게임명 자리에 그 판의 **플레이 방식**이 들어가고,
> 요약의 세 번째 칸이 `게임` 수 대신 **평균 인원**으로 바뀝니다.

**미보유 플레이**는 지금 보유 여부가 아니라 **그 판을 하던 시점**의 보유 여부로 판정합니다.
갖고 있을 때 기록한 판은 나중에 게임을 팔아도 여기 들어오지 않습니다 → [6.3 지표 사전](../../06-insights/metrics/)
