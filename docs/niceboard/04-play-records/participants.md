## 참가자 넣기

**참가자 및 점수** 섹션에서 관리합니다.

| 방법 | 어떻게 |
|---|---|
| **직접 입력** | 이름 칸에 타이핑 |
| **친구에서 고르기** | 참가자 행의 👥 아이콘 → **친구 또는 사용자에서 선택** |
| **모임 통째로** | 헤더의 **모임** 버튼 → 모임 고르기 → 그 모임 멤버로 명단 교체 |
| **한 명 더** | **인원 추가** 버튼 (섹션 헤더와 참가자 목록 맨 아래 두 곳) |

첫 번째 행은 항상 **나**입니다 (**(나)** 표시).
새 기록은 이 **나** 한 행으로 시작합니다 — 필요한 사람만 넣으면 됩니다.

**인원 추가**를 누르면 새 행이 목록 **맨 아래**에 생기고,
화면이 그 행으로 스크롤되며 이름 칸에 커서가 놓입니다 — 바로 이름을 치면 됩니다.
인원이 많을 때 새 행을 놓치지 않도록 목록 맨 아래에도 같은 버튼이 있습니다.

{: .note }
> 친구로 등록해 둔 사람을 고르면 이름이 정확히 일치하므로
> **친구 상세의 1:1 전적**과 **모임 리더보드**가 자동으로 채워집니다.
> 매번 다르게 타이핑하면 같은 사람으로 세지 않습니다 → [9.3 전적 집계 규칙](../../09-friends-groups/stats-rules/)

### 모임 불러오기

**모임** 버튼을 누르면 모임 목록(이름 + 멤버 수 + 멤버 미리보기)이 나옵니다.
고르면 참가자 명단이 **그 모임의 멤버로 바뀝니다**.

- **내 행(첫 번째)은 항상 그대로**입니다
- 다른 모임을 다시 고르면 **합쳐지지 않고 교체**됩니다 — 모임을 바꿔 고르는 건 정정이니까요
- **양쪽 모임에 다 있는 사람**은 그 행이 유지되므로 이미 입력한 점수·역할이 남습니다
- 빠지는 사람 중 **점수나 역할을 입력한 사람이 있으면 확인 창**이 뜹니다 (`… 계속할까요?`)
- 결과 메시지: `'모임명' 멤버 N명으로 교체됨` 또는 `'모임명' 멤버 그대로예요`

여러 모임이 함께 한 판이라면, 한 모임을 부른 뒤 나머지는 **인원 추가**로 넣으세요.

### 기본 모임
{: #기본-모임 }

늘 같은 사람들과 한다면 **모임 하나를 기본으로 지정**해 두세요.
새 플레이 기록 화면에 들어가는 순간 **나 + 그 모임 멤버**가 참가자 행으로 채워져 있어,
점수만 넣고 저장하면 됩니다.

지정은 **친구·모임 탭 → 모임 → 멤버 카드의 '기본 모임' 스위치**로 합니다
([9.2 모임](../../09-friends-groups/groups/#기본-모임)).

- 채워지면 참가자 헤더 아래에 `기본 모임 '모임명' 기준` 캡션이 뜹니다
- 오늘은 다른 사람들과 한다면 참가자 행의 **X** 로 지우면 됩니다
- 기본 모임은 **한 개**만 지정할 수 있습니다 (다른 모임을 지정하면 이전 것은 풀립니다)
- 1인 플레이 기록에는 채워지지 않습니다

## 1인 플레이 (솔플)

점수 시트 위쪽의 **1인 플레이 (솔플)** 스위치를 켜면 혼자 한 판으로 기록됩니다.

{: .warning }
> 여러 명이 입력된 상태에서 솔플로 전환하면
> *"1인 플레이로 전환하면 첫 번째 참가자 외 다른 참가자 정보와 점수가 삭제됩니다."*
> 확인 창이 뜹니다.

1인 전용 템플릿을 쓰면 이 스위치가 켜진 채로 고정됩니다.

## 역할 (캐릭터 · 진영)
{: #역할 }

참가자 행의 **캐릭터/진영/역할 선택**을 탭하면 값 피커가 열립니다.
테라포밍 마스에서 맡은 기업, 스콜지 인베이전의 진영 같은 것을 기록하는 자리입니다.

### 역할은 여러 개 고를 수 있습니다

솔로 2핸드나 멀티 캐릭터 플레이를 위해 **한 참가자가 여러 역할**을 가질 수 있습니다.

- 목록을 탭하면 **선택 토글**입니다 (여러 개 켜기)
- 고른 순서가 유지되며 **첫 번째가 대표**로 쓰입니다
- **완료**를 눌러야 확정됩니다. 그냥 닫으면 변경되지 않습니다

### 값 피커 사용법
{: #값-피커-사용법 }

이 피커는 역할뿐 아니라 플레이 방식 · 텍스트 항목 · 게임 공통 항목에서도 똑같이 쓰입니다.

| 요소 | 하는 일 |
|---|---|
| **목록** | 이 게임에서 전에 쓴 값들. 오른쪽 숫자(`14회`)는 이 게임에서 그 값을 쓴 횟수입니다 |
| **직접 입력** | 목록에 없는 새 값을 추가 |
| **🎲 랜덤 선택** | 아직 안 고른 것 중에서 추첨합니다. 룰렛처럼 돌다가 멈춥니다 |
| **지우기** | 선택을 전부 해제 |

![역할 값 피커](/docs/niceboard/assets/screenshots/role-picker.webp){: .screenshot }
*고른 값은 위쪽에 칩으로 모입니다. 목록의 `14회` 는 이 게임에서 그 역할을 쓴 횟수입니다*

## 값 이름 바꾸기 · 지우기

값 피커에서 항목을 **길게 누르면** 관리 메뉴가 나옵니다 — **이름 변경** / **기록에서 삭제**.

{: .warning }
> **이것은 과거 기록을 실제로 바꾸는 작업입니다.**
> 확인 창이 이렇게 경고합니다 — *"이 게임의 과거 플레이 기록에 저장된 값이 실제로 수정되며,
> 관련 통계도 함께 바뀝니다. 되돌릴 수 없습니다."*
>
> 오타를 고칠 때(`엘프` → `엘프족`)는 유용하지만, 실행 전에 꼭 확인하세요.

값 목록은 과거 기록을 모아 만든 것이라, 목록을 정리하려면 기록 자체를 고칠 수밖에 없습니다.
이 기능은 역할과 플레이 방식에서만 지원됩니다.

## 역할이 통계에 쓰이는 방식

게임 통계 화면의 **역할별 성적** 카드에서 볼 수 있습니다 ([6.2](../../06-insights/game-stats/)).

- 기본 스코프는 **나** — 내가 맡은 역할의 승률
- **전체**로 바꾸면 모든 참가자 기준 — "어떤 진영이 강한가"
- **참가자**를 고르면 그 사람 기준

{: .note }
> **한 판에서 역할을 여러 개 맡았다면 각 역할 칸에 1판씩** 들어갑니다.
> 그래서 역할별 판수를 다 더하면 실제 판수보다 많을 수 있습니다. 의도된 계산입니다.
