# 4.6 라이브 세션
{: .no_toc }

게임을 **하는 동안** 쓰는 도구 모음입니다.
타이머로 시간을 재고 점수패드로 점수를 매기다가, 게임이 끝나면 **측정한 값이 기록 화면에 그대로 채워집니다.**

{:toc}

## 시작하기

| 경로 | 방법 |
|---|---|
| **홈 → 새 플레이 기록** | 위쪽 토글을 **라이브 세션**으로 바꾼 뒤 게임을 탭 |
| **게임 상세** | **라이브 세션 시작** 버튼 |

---

## 설정 시트

세션에 들어가기 전 준비 화면입니다.

| 항목 | 설명 |
|---|---|
| **참가자 (N명)** | **참가자** 버튼으로 고르거나 **모임 불러오기**로 한꺼번에. 이름을 탭하면 변경 |
| **점수 템플릿** | 이 판에 쓸 점수 시트 |
| **솔로 플레이** | 혼자 하는 판 |
| **플레이 중 화면 켜두기** | *"타이머가 잘 보이도록 화면이 꺼지지 않게 합니다."* 기본 켜짐 |

참가자와 템플릿은 그 게임의 **최근 기록에서 미리 채워집니다** (`최근 기록 기준` 캡션) → [4.5](../quick-copy/#라이브-세션에도-같은-기능이-있습니다)

**세션 시작**을 누르면 도구 화면으로 들어갑니다.

---

## 세션 화면

맨 위에 **항상 보이는 시간 스트립**이 있습니다 — 전체 경과 시간, 시작/일시정지, 카운트다운 남은 시간, 선플레이어.

그 아래로 네 개의 패널을 세그먼트로 전환합니다.

### 타이머

| 기능 | 설명 |
|---|---|
| **전체 플레이 시간** | 카운트업. 시작 / 일시정지 / 🔄 리셋 |
| **카운트다운** | 분 단위로 설정. 0이면 끕니다. 다 되면 *"제한 시간이 지났습니다. (게임은 계속 진행할 수 있어요)"* — 게임을 막지는 않습니다 |
| **플레이어별 시간 (체스클록)** | 타일을 **탭하면 턴 넘김**. 각자 얼마나 오래 고민했는지 쌓입니다 |
| **턴 제한** | 초 단위. 넘기면 분석마비 알림. 0이면 끕니다 |

{: .note }
> 체스클록 타일을 **길게 누르면 역할 지정**입니다 (탭은 턴 넘김이라 롱프레스를 씁니다).
> 지정한 역할은 이름 아래에 표시되고, 세션이 끝나면 기록 화면에 그대로 실려 갑니다.

시간은 실제 시계를 기준으로 계산하므로 앱을 잠깐 백그라운드로 보내도 어긋나지 않습니다.

### 점수패드

플레이어 × 항목 표에서 **+/−** 로 점수를 올리고 내립니다.

- **증분 칩**으로 한 번에 더할 값을 고릅니다 (+1 / +5 / +20 / **직접**)
- **되돌리기**로 방금 조작을 취소합니다
- **이름을 탭하면 역할을 지정**합니다
- 합계는 기록 입력 화면과 같은 방식으로 계산됩니다

점수 항목이 없는 템플릿에서는 이렇게 안내합니다 —
*"이 템플릿은 점수 카테고리가 없습니다. 카운터 탭의 범용 카운터를 사용하거나, 게임 종료 후 기록 화면에서 승패를 입력하세요."*

{: .note }
> **텍스트 항목과 게임 공통 항목은 점수패드에 나오지 않습니다.**
> 숫자가 아니기 때문이며, 세션이 끝난 뒤 기록 화면에서 입력합니다.

<!-- screenshot: live-scorepad.png -->

### 카운터

점수와 상관없는 아무 숫자나 셉니다 — 생명, 자원, 라운드 등.

- **+ 카운터**로 이름을 붙여 추가합니다 (예: `생명`, `자원`, `라운드`)
- 증분 칩과 **되돌리기**는 점수패드와 같습니다
- 카운터를 **길게 누르면 삭제**

### 도구

**턴 순서 섞기 · 주사위** 카드를 누르면 열립니다.

| 기능 | 설명 |
|---|---|
| **순서 섞기** | 슬롯머신처럼 돌다가 멈춥니다. **1등이 선플레이어**가 되고 실제 순서도 반영됩니다 |
| **주사위** | 개수를 정해 **굴리기**. d6은 실제 눈이 그려집니다. 합계도 나옵니다 |
| **범위 난수** | 최소~최대를 정해 뽑습니다 |

## 게임을 끝낼 때

오른쪽 위 **🚩 게임 종료**를 누르면 확인 창이 뜹니다 —
*"게임을 종료하고 기록 저장 화면으로 갈까요? 측정한 시간·점수·선플레이어가 자동으로 채워집니다."*

넘어가면 **기록 입력 화면**이 이렇게 채워져 있습니다.

- 참가자와 역할
- 항목별 점수
- 전체 플레이 시간
- 선플레이어
- (한줄평이 비어 있으면) 플레이어별 시간과 카운터 요약이 **자동 작성**

여기서 날짜 · 장소 · 확장팩 등을 마저 넣고 **저장**하면 끝입니다.

{: .warning }
> **뒤로 가기로 나가면 측정값이 사라집니다.**
> *"진행 중인 라이브 세션을 종료할까요? 기록하지 않으면 측정값이 사라집니다."*
> 확인 창이 막아 주지만, 기록을 남기려면 반드시 **게임 종료**로 나가세요.
