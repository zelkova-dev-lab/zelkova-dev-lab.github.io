# 4. 플레이 기록
{: .no_toc }

나이스보드의 심장입니다. 여기 쌓인 기록이 통계 · 챌린지 · 배지 · 모임 전적의 재료가 됩니다.

기록하는 방법은 두 가지입니다.

- **바로 기록** — 게임이 끝난 뒤 결과를 입력합니다.
- **라이브 세션** — 게임 *하는 동안* 타이머 · 점수패드 · 카운터를 쓰고, 끝나면 측정값이 기록 화면에 자동으로 채워집니다.
