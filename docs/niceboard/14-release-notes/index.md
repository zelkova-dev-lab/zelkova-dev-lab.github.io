# 14. 업데이트 기록
{: .no_toc }

버전별로 무엇이 새로 생기고 무엇이 바뀌었는지 모아 둔 페이지입니다.
"이 기능이 원래 있었나?" 싶을 때, 또는 오랜만에 앱을 열었을 때 훑어 보세요.

**내가 쓰는 버전**은 **내 정보** 화면 맨 아래에 표시됩니다.
업데이트는 Play 스토어에서 받으며, 새 버전이 나오면 앱이 알려줍니다
([11.4 설정](../11-data-settings/settings/)).

{: .note }
> 최신 버전은 **1.5.7** (2026년 8월 21일)입니다.
> 여기 적힌 것은 사용자에게 보이는 변화만입니다 — 내부 개선이나 성능 수정은 생략했습니다.

---

## 1.5.7 — 2026년 8월 21일

- **게임 검색이 훨씬 잘 걸립니다** ([3.1 게임 검색](../03-games/search/))
  - 띄어쓰기 없이, 이름 중간부터 입력해도 찾아집니다 (포밍마스, 헤이븐 등)
  - 초성 검색 지원 (ㅂㄹㅅ)
  - 한글 이름과 원어 이름을 함께 검색
- **플레이 기록** ([4.2 참가자와 역할](../04-play-records/participants/))
  - 기록할 때 자동으로 들어가던 '친구 1' 제거
  - 모임 멤버를 통째로 참가자로 불러오기
  - 기본 모임을 지정해 두면 기록할 때마다 참가자가 자동으로 채워집니다
- **통계** ([6.1 인사이트 탭](../06-insights/insights-tab/))
  - '많이 즐긴 작가 · 퍼블리셔' 추가
  - 특정 친구와 함께한 날 · 게임 수 · 시간 통계 추가

## 1.5.6 — 2026년 8월 16일

- **새 기능**
  - **「모두의 통계」** — 인사이트 탭에서 전체 이용자의 인기 게임, 요즘 뜨는 게임, 장르 · 요일 분포, 거래 성향을 봅니다. 개인 금액과 이름은 집계에서 빠집니다 ([6.4 모두의 통계](../06-insights/everyones-stats/))
  - **사용설명서** — 내 정보 → 지원 → 사용설명서 (지금 보고 있는 이 문서입니다)
- **개선**
  - 게임 검색: 타이핑하는 동안 결과가 바로 나오고, 엔터를 누르면 BGG까지 넓혀 찾습니다
  - 표시 이름이 어디까지 보이는지 안내 추가

## 1.5.5 — 2026년 8월 9일

- **새 기능**
  - **선주문/펀딩** — 수령 예정일과 함께 등록하면 가계부에 지출이 먼저 잡히고, 수령 완료를 누르면 보유 게임으로 자동 전환됩니다 ([2.5 선주문/펀딩 완전 가이드](../02-collection/preorder/))
  - **확장판 묶어 보기** — 보유 목록에서 확장이 본판 아래로 묶이고, 보유 개수는 본판 기준으로 셉니다 ([2.4 본판과 확장](../02-collection/expansions/))
- **개선**
  - 한글명 제안에 '제안 이유' 입력 칸 추가
  - 의견에 답변이 달리면 메일로 알려 줍니다
  - BGG 동기화 · BG Stats 백업/복원에서도 선주문 상태 유지
- **버그 수정**
  - 홈 화면 카드에 게임 이름이 잘못 나오던 문제 수정

## 1.5.4 — 2026년 8월 1일

- **모임 기능 추가** ([9.2 모임](../09-friends-groups/groups/))
  - 친구들을 모임으로 묶어 모임별 순위표와 전적 확인
  - 게임 통계 · 인사이트에서 모임별 성적 확인
  - '모임 노트' 이미지 공유
- **의견 보내기 추가** ([12.4 의견 보내기](../12-faq/feedback/))
  - 앱 안에서 버그 제보 · 개선 의견 접수
  - 처리 상태와 답변 확인
- **플레이 기록 개선**
  - 한 사람이 여러 역할을 맡는 기록(솔로 2핸드 등) 지원
  - 순위만 적은 기록의 통계 정확도 향상
- **버그 수정**
  - 게임 난이도 · 평점 표시 오류 수정
  - 순위표 전적 숫자가 잘리던 현상 수정
  - 게임 통계 필터 사용성 개선

## 1.5.3 — 2026년 7월 26일

- **게임별 통계** — 개별 게임의 플레이 빈도와 승률을 따로 봅니다 ([6.2 게임별 통계와 고급 필터](../06-insights/game-stats/))
- **상세 기록** — 역할과 플레이 방식(맵 · 시나리오 · 모드) 입력 ([4.4 플레이 방식 · 확장팩 · 시간](../04-play-records/details/))

## 1.5.2 — 2026년 7월 14일

- **새 기능**
  - **홈 히트맵** — 최근 1년 플레이 현황을 잔디 모양으로
  - **인사이트** — 보유 기간 통계와 '장롱 지수' 카드
- **개선**
  - **업적 배지 리뉴얼** — 34종 배지를 인장(도장) 디자인으로 전면 교체 ([8. 업적 배지](../08-badges/))
  - **데이터 관리** — 내 정보 화면 개편, 백업/복원을 '데이터 관리'로 통합
  - 챌린지 목록에서 완료 항목 접기, 다크 모드 가시성 개선
  - 플레이 · 거래 기록 필터 강화, 한글명 적용 범위 확대

## 1.5.1 — 2026년 7월 11일

- **새 기능**
  - **데이터 복구/초기화** — 가져오기 직전 상태 자동 저장과 되돌리기, 항목별 선택 삭제 ([11.3 삭제와 초기화](../11-data-settings/deleting/))
- **개선**
  - 기록 목록에 체크박스와 전체 선택 노출
- **버그 수정**
  - BG Stats 백업을 가져올 때 날짜가 잘못 등록되던 문제 수정

## 1.5.0 — 2026년 7월 4일

- **새 기능**
  - **업적 배지** — 활동 기반 배지 34종과 동 · 은 · 금 티어, 이미지 공유
- **개선**
  - 컬렉션 정렬 추가, 한글명 제안 시스템(철회 · 채택 표시 등) 개선
  - 검색 순위와 목록 건수 표시 등 화면 정리
- **버그 수정**
  - 거래 입력 중 화면을 벗어나면 내용이 사라지던 문제, 글자 잘림 수정

## 1.4.1 — 2026년 6월 29일

- '추리 · 탐정' 장르 신설과 게임 재분류
- 측정한 시간을 직접 고치고 이어서 잴 수 있게 개선
- 기록 입력 중 이탈 방지 확인 창, 홈 화면 동선 정리

## 1.4.0 — 2026년 6월 28일

- **새 기능**
  - 플레이 성향 레이더 그래프와 월간 플레이 달력
  - **라이브 세션** — 타이머 · 점수판 등 게임 중 도구와 자동 기록 저장 ([4.6 라이브 세션](../04-play-records/live-session/))
  - **다크 모드** 정식 지원
- **개선**
  - 인원수 · 난이도 필터 강화, 플레이와 거래 이력 탭 통합

## 1.3.0 — 2026년 6월 20일

- 컬렉션 · 플레이 · 챌린지 상세 공유 카드와 챌린지 알림 추가 ([10. 공유하기](../10-sharing/))

## 1.2.4 — 2026년 6월 14일

- BGG 카테고리별 랭킹, 챌린지 대상 게임 선택 기능 추가
- 보유 게임 정렬 기준 개선, 데이터 관리 안정성 강화

## 1.2.3 — 2026년 6월 10일

- 네이버 · 카카오 로그인 안정성 개선

## 1.2.2 — 2026년 6월 8일

- 네이버 로그인 추가

## 1.2.1 — 2026년 6월 6일

- 카카오 로그인 추가

## 1.2.0 — 2026년 6월 6일

- BGG 플레이 기록 가져오기, 1인 플레이 기록 지원
- 소셜 로그인 편의성, 플레이 정보 복사, 한글명 제안 사용성 개선

## 1.1.2 — 2026년 6월 2일

- 다건 거래 일괄 등록 추가

## 1.1.0 — 2026년 5월 31일

## 1.0.16 ~ 1.0.21 — 2026년 5월 23일 ~ 28일

- 유저 찾기에서 바로 친구 등록, 주요 버튼 햅틱 피드백 (1.0.20)
