## 컬렉션

| 용어 | 뜻 |
|---|---|
| **보유 중** | 지금 갖고 있는 게임. 최신 거래에서 자동으로 정해집니다 |
| **위시리스트** | 갖고 싶은 게임 |
| **즐겨찾기** | 자주 꺼내 보는 단축 목록. 다른 상태와 무관하게 켤 수 있습니다 |
| **선주문/펀딩** | 결제는 했지만 아직 못 받은 상태. 지출에는 잡히고 보유로는 안 셉니다 |
| **수령 완료** | 선주문한 물건이 도착해 보유로 옮기는 것 |
| **본판** | 확장이 아닌 기본 게임 |
| **확장 N개 보유** | 그 본판의 확장을 N개 갖고 있다는 뱃지 |
| **고아 확장** | 본판 없이 갖고 있는 확장. `확장` 뱃지가 붙고 보유 수에서 제외됩니다 |

## 기록

| 용어 | 뜻 |
|---|---|
| **플레이 방식** | 이번 판의 맵 · 시나리오 · 모드 · 룰 변형. 판당 하나 |
| **역할** | 참가자가 맡은 캐릭터 · 진영. 한 사람이 여러 개 가질 수 있습니다 |
| **역할 조합** | 한 판에 함께 쓰인 서로 다른 역할들의 묶음 |
| **점수 항목** | 참가자마다 입력하는 숫자 |
| **텍스트 항목** | 참가자마다 입력하는 글자 (리더 · 종족 등) |
| **게임 공통 항목** | **판당 하나만** 입력하는 글자 (시나리오 · 난이도 등) |
| **선 플레이어** | 그 판을 먼저 시작한 사람 |
| **라이브 세션** | 게임 하는 동안 쓰는 타이머 · 점수패드 · 카운터 도구 |
| **체스클록** | 플레이어별 소요 시간을 재는 시계. 타일을 탭하면 턴이 넘어갑니다 |
| **미지정 / 없음** | 장소를 비우면 `미지정`, 승자를 비우면 `없음`으로 저장됩니다 |

## 거래와 금액

| 용어 | 뜻 |
|---|---|
| **구매** | 게임이나 용품을 산 거래 |
| **방출** | 팔거나 넘긴 거래 |
| **수집 누적액** | 돈이 나간 거래(구매 + 선주문)의 합 |
| **방출 회수액** | 방출로 돌려받은 금액의 합 |
| **소비액** | 수집 누적액 − 방출 회수액. "실제로 쓴 돈" |
| **세이브** | 소비액이 음수일 때의 표시. 판 돈이 더 많다는 뜻 |
| **경로** | 어디서 사고팔았는지 (보드라이프 · 당근마켓 등) |
| **방식** | 온라인 / 오프라인 |
| **상태** | 신규 / 중고 |
| **완결 거래(사이클)** | 구매 → 방출까지 끝난 한 쌍 |

## 통계

| 용어 | 뜻 |
|---|---|
| **H-Index** | N번 이상 플레이한 게임이 N가지 있을 때의 N. 다양성과 반복을 함께 잽니다 |
| **승률** | 내가 이긴 판 ÷ 전체 판. "나"는 참가자 첫 번째 자리 |
| **미보유 플레이** | **그 판을 할 때** 갖고 있지 않았던 기록 |
| **장롱 지수** | 오래 갖고 있는데 잘 안 하는 정도. 연환산 플레이 횟수 기준 |
| **장롱 TOP / 알뜰 TOP** | 각각 가장 안 하는 게임 / 가장 본전 뽑은 게임 |
| **플레이 스타일** | 복잡도 · 사교성 · 호흡 · 협력성 · 다양성 · 최신성 6축 |
| **플레이 일수** | 며칠에 걸쳐 플레이했는가 (판수와 다릅니다) |
| **판 중복 가능** | 같은 판이 여러 모임에 잡힐 수 있다는 뜻 |
| **참가자 식별이 가능한 판** | 참가자 정보가 남아 있어 누가 이겼는지 알 수 있는 판 |
| **드릴다운** | 통계 행을 탭해 그 조건의 플레이 목록을 보는 것 |

## 친구와 모임

| 용어 | 뜻 |
|---|---|
| **친구** | 자주 같이 노는 사람. 이름만 등록해도 되고 계정을 연결할 수도 있습니다 |
| **연결됨** | 나이스보드 사용자 계정과 연결된 친구 |
| **모임** | 친구를 묶은 그룹. "나"는 항상 포함됩니다 |
| **모임 순위(리더보드)** | 모임 멤버별 판수 · 승수 · 승률 |
| **1:1 전적** | 나와 그 친구가 함께 참가한 판의 승패 |
| **모임 스코프** | 그 모임 멤버가 1명 이상 참가한 판의 범위 |

## 챌린지와 배지

| 용어 | 뜻 |
|---|---|
| **10x10** | 게임 10개를 각각 10번씩 플레이하는 목표 |
| **미플레이 탈출** | 한 번도 안 해 본 보유 게임을 꺼내는 목표 (Shelf of Shame) |
| **연속 N일** | 며칠 연속으로 기록을 남겼는가. 하루에 몇 판을 하든 1일 |
| **정기 플레이** | 매주 목표 횟수를 채우는 습관 목표 |
| **도전 티켓** | 챌린지를 확정하기 전 마지막 확인 화면 |
| **티어** | 배지의 단계 — 동 · 은 · 금 |
| **승급** | 배지가 상위 티어로 올라가는 것. 강등은 없습니다 |
