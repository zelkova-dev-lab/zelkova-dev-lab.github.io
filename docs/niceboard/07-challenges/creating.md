## 만들기

**챌린지 탭 → 오른쪽 위 +** (`새로운 도전 시작`)

**새로운 챌린지 열기** 시트가 열립니다. 위에서부터 순서대로 고르면 다음 단계가 나타납니다.

### 1단계 — 대분류 선택

**일반 챌린지 / H-Index 챌린지 / 플레이어 챌린지 / 시간 및 습관**

### 2단계 — 세부 과제 선택

고른 대분류의 세부 유형 칩이 나옵니다 → [7.1 챌린지 종류](../types/)

![챌린지 만들기 시트](/docs/niceboard/assets/screenshots/challenge-ticket.webp){: .screenshot }
*대분류를 고르면 세부 과제가, 세부 과제를 고르면 목표 설정이 차례로 나타납니다*

### 3단계 — 기간 설정

기본값은 **올해 1월 1일 ~ 12월 31일**입니다. 버튼을 눌러 바꿉니다.

{: .note }
> 진행률은 **이 기간 안의 기록만** 셉니다.
> 기간을 잘못 잡으면 이미 한 판들이 반영되지 않으니 확인하세요.

### 4단계 — 목표 설정

세부 유형에 따라 **− / +** 버튼이 나옵니다 (최솟값 1, 상한 없음).
예: `도전할 보드게임 수 3개`, `각 게임당 목표 플레이 횟수 5회`

승률 목표만 드롭다운(30% / 40% / 50% / 60% / 70%)입니다.

### 5단계 — 게임 고르기

**10x10 · 5x5 · NxN**에서만 나옵니다.

- 헤더에 `도전 게임 지정 (N / M)`, 개수가 안 맞으면 **`정확히 M개를 선택하세요.`** (주황), 맞으면 `목표 개수 도달 완료!` (초록)
- 탭 네 개: **내 소유 게임 / 즐겨찾기 / 최근 플레이 / 직접 검색 추가**
- 고른 게임은 `선택한 게임 목록 (탭하여 취소)`에 칩으로 모입니다
- **목표 개수를 채우면 나머지 게임은 자동으로 못 고르게 됩니다**

**직접 검색 추가** 탭은 두 글자부터 자동으로 찾아 줍니다. 오른쪽 버튼은
영문으로 검색할 때 **BGG까지**, 한글로 검색할 때 **다시 검색**으로 바뀝니다 →
[공통 조작](../../01-getting-started/screen-map/#게임-검색은-두-글자부터-자동입니다)

**보유게임 N회**는 대신 체크리스트가 나오고, 빠른 선택 칩이 있습니다 —
`전체 선택` · `선택 해제` · `플레이 적은 순 5개` · `플레이 적은 순 10개` · `최근 등록 순 5개` · `최근 등록 순 10개`

칩 아래 **내 보유게임 검색** 칸으로 목록을 좁힐 수 있습니다. 띄어쓰기를 빼거나 이름 중간부터, 초성으로 쳐도 됩니다.
담을 때 영어 이름이었더라도 **지금 화면에 보이는 한글 이름으로 찾을 수 있습니다.**

### 6단계 — 도전 티켓

**새로운 도전 시작하기**를 누르면 티켓 모양의 확인 창이 뜹니다.

| 부분 | 내용 |
|---|---|
| **도전 요약** | 도전 유형 · 상세 조건 · 도전 기간 |
| **챌린지명 설정** | 자동으로 이름이 채워져 있고, 여기서 고칠 수 있습니다 |

자동 이름 예: `2026년 10x10 플레이 도전!`, `나의 보드게임 H-Index 10 정복!`

![도전 티켓](/docs/niceboard/assets/screenshots/challenge-ticket2.webp){: .screenshot }
*도전 요약을 확인하고 챌린지명을 정하면 등록됩니다 (사진은 기존 챌린지를 수정할 때의 티켓)*

**도전 시작하기**를 누르면 등록됩니다 —
`새로운 플레이 챌린지가 등록되었습니다! 화이팅!`

{: .note }
> 챌린지 이름은 **이 티켓에서만** 입력합니다. 앞 단계에는 이름 칸이 없습니다.
> 비우고 확정하면 *"챌린지명을 한 글자 이상 입력해 줘!"* 경고가 나옵니다.

---

## 진행률은 저절로 올라갑니다

플레이 기록을 저장할 때마다 앱이 모든 챌린지를 다시 계산합니다.
챌린지 화면에서 새로고침할 필요가 없습니다.

과거 날짜의 기록을 나중에 입력해도, 그 날짜가 챌린지 기간 안이면 바로 반영됩니다.

## 목록 다루기

### 검색과 필터

| 컨트롤 | 내용 |
|---|---|
| **검색창** | `챌린지명 또는 게임명 검색` — 포함된 게임 이름으로도 찾습니다 (한글명 매칭). 띄어쓰기를 빼거나 이름 중간부터, 초성으로 쳐도 됩니다 → [공통 조작](../../01-getting-started/screen-map/#이름을-정확히-몰라도-찾아-줍니다) |
| **상태 칩** | 전체 / 진행중 / 완료 |
| **추가 필터** | 도전 기간 · 챌린지 대분류 · 세부 유형 |

{: .warning }
> 추가 필터 시트는 **필터 적용**을 눌러야 반영됩니다 → [공통 조작 규약](../../01-getting-started/screen-map/#필터-시트는-필터-적용을-눌러야-반영됩니다)

### 정렬

**진행중 우선**(기본) / 최신 등록순 / 오래된 등록순 / 진행률 높은순 / 진행률 낮은순

### 카드에서 할 수 있는 것

카드의 **⋮ 더보기** 메뉴:

- **공유** — 챌린지 카드 이미지 만들기
- **수정** — 목표·기간·게임 바꾸기 (대분류와 세부 유형은 못 바꿉니다)
- **삭제**

게임 목록이 긴 카드는 **나머지 N개 도전게임 더 보기 / 리스트 간략히 접기**로 접었다 폅니다.

## 등록이 막힐 때

| 메시지 | 뜻 |
|---|---|
| `챌린지에 포함할 보드게임을 최소 한 개 이상 지정해 줘! 🃏` | 게임을 하나도 안 골랐습니다 |
| `{유형} 챌린지를 시작하려면 정확히 M개의 게임을 선택해야 합니다.` | 개수가 안 맞습니다 |
| `선택한 보드게임이 없어 보유 챌린지를 개설할 수 없습니다.` | 보유게임 N회에서 전부 해제했습니다 |
| `아싸! 미플레이 보드게임(Shelf of Shame)이 전혀 없어 등록할 필요가 없습니다!` | 미플레이 게임이 없습니다 |
