# 10. 공유하기 — 플레이 노트
{: .no_toc }

기록과 통계를 **손으로 쓴 노트 한 장** 같은 이미지로 만들어 단톡방이나 SNS에 공유합니다.

1. TOC
{:toc}

---

## 공통 흐름

어느 카드든 방식이 같습니다.

```
↗ 아이콘 → 미리보기 (옵션 조정) → [공유하기] → 안드로이드 공유 시트
```

- 이미지를 만드는 동안 `준비 중…`이 표시됩니다
- 공유 문구에는 **`#나이스보드`** 해시태그가 붙습니다

{: .note }
> **공유 이미지는 다크 모드에서도 항상 밝은 종이색**으로 만들어집니다.
> 앱 밖의 아무 배경 위에 올라가기 때문에 밝은 쪽이 잘 읽힙니다.
> 시트 자체(배경·버튼)만 앱 테마를 따릅니다.

---

## 카드 아홉 종류

| 카드 | 무엇을 담나 | 어디서 |
|---|---|---|
| **오늘의 플레이 카드** | 한 판의 기록 | 기록 카드 오른쪽 위 ↗ · 기록 상세 시트 |
| **기간 플레이 노트** | 기간 플레이 요약 | 인사이트 오른쪽 위 ↗ |
| **내 플레이 성향** | 성향 레이더 | 위와 같은 화면 (넘겨서 선택) |
| **내 게임 선반** | 커버 콜라주 | 컬렉션 **보유 중** 탭 → ▦ |
| **보드게임 가계부** | 기간 지출·손익 | 내 기록 → 거래 탭 ↗ |
| **챌린지 카드** | 챌린지 진행·달성 | 챌린지 카드 ⋮ → 공유 |
| **배지 자랑하기** | 배지 하나 | 배지 상세 시트 → 자랑하기 |
| **배지 진열장** | 배지 모음 | 배지 화면 오른쪽 위 ↗ |
| **게임 노트** | 한 게임의 통계 | 게임 통계 오른쪽 위 ↗ |
| **모임 노트** | 모임 순위표와 통계 | 모임 상세 ↗ · 인사이트 모임 카드 ↗ |

## 카드별 옵션

### 오늘의 플레이 카드

한 판을 노트 카드 한 장으로 만듭니다.
게임명 · 날짜 도장 · 커버 · 장소 · 플레이 방식 · 승자 · 플레이 시간 · 한줄평이 들어갑니다.

| 옵션 | 기본값 |
|---|---|
| **참가자별 점수 보이기** | 꺼짐 |
| **세부 점수까지 보이기** | 꺼짐 |

{: .note }
> 참가자 점수는 **기본으로 숨겨집니다.** 다른 사람의 점수가 그대로 공개되는 것을 막기 위해서입니다.
> 필요하면 스위치로 켜세요.

### 기간 플레이 노트 / 내 플레이 성향

인사이트의 ↗로 들어가면 **두 장을 넘겨 보며** 고릅니다.
아래 **공유하기** 버튼을 눌러야 확정됩니다.

### 내 게임 선반

보유 게임 커버를 선반에 늘어놓은 콜라주입니다.

| 옵션 | 값 |
|---|---|
| **정렬** | 플레이순 / 최근순 / 이름순 |
| **커버 숨기기** | *"커버를 탭하면 선반에서 숨길 수 있어요"* |
| **숨긴 N개 되돌리기** | 숨긴 것을 되살립니다 |

선주문 중인 게임은 **도착 예정**으로 표시됩니다.

### 보드게임 가계부

**올해 / 전체** 중에서 고릅니다. 기간 지출·손익과 영입한 게임이 들어갑니다.

### 게임 노트

**필터 반영 / 전체 기록** 중에서 고릅니다.
게임 통계에 필터를 걸어 둔 상태로 공유하면 그 조건이 그대로 반영됩니다.

{: .note }
> 필터를 건 결과가 너무 적으면 자동으로 전체 기록으로 되돌아갑니다.

### 모임 노트

| 옵션 | 값 |
|---|---|
| **기간** | 전체 / 올해 |
| **범위** | 모임 전체 / 특정 게임 |

모임 상세에서 게임 행을 **길게 누르면** 그 게임 범위로 바로 열립니다.

### 배지 진열장

| 모드 | 내용 |
|---|---|
| **전체 진열장** | 34종 전부 (못 얻은 것은 흐리게) |
| **획득만** | 얻은 배지만 |
| **올해의 배지첩** | 올해 얻은 배지 |

얻은 배지가 10개 미만이면 기본이 **획득만**으로 잡힙니다.
12월~1월 중순에는 홈 화면에 `{연도}년 배지첩 정리하기` 배너가 나옵니다.

---

## 어떤 톤인가요

앱 전체와 같은 **양피지 · 잉크** 톤입니다.

- 종이 질감 바탕에 손으로 그은 밑줄
- 커버는 테이프로 붙인 폴라로이드처럼
- 차트는 손으로 그린 듯한 막대
- 날짜와 뱃지는 도장 느낌

필요하면 참가자 점수 표시를 꺼 두세요.
