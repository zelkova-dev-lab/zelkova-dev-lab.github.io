# 1.1 나이스보드는 어떤 앱인가요
{: .no_toc }

한 줄로 말하면 **보드게임 생활을 기록하는 노트**입니다.
무엇을 갖고 있고, 무엇을 얼마나 했고, 얼마를 썼는지가 한 앱에 모입니다.

1. TOC
{:toc}

---

## 다섯 개의 기둥

나이스보드의 모든 화면은 이 다섯 가지 중 하나입니다.

| 기둥 | 무엇을 담나 | 어디에 |
|---|---|---|
| **컬렉션** | 보유 · 위시리스트 · 즐겨찾기 · 선주문/펀딩 | 컬렉션 탭 |
| **플레이 기록** | 언제 누구와 어떻게 놀았는지 | 내 기록 → 플레이 |
| **거래** | 게임과 용품을 사고판 이력 | 내 기록 → 거래 |
| **챌린지** | 스스로 세운 목표와 진행률 | 챌린지 탭 |
| **인사이트** | 위 넷에서 뽑아낸 통계 | 인사이트 탭 |

---

## 기록 하나가 만드는 것

플레이 기록을 하나 남기면 여러 곳이 동시에 움직입니다.
따로 갱신할 필요가 없습니다.

```
        플레이 기록 저장
              │
   ┌──────────┼──────────┬──────────┐
   ▼          ▼          ▼          ▼
 승률·통계   챌린지 진행  배지 판정   모임 전적
```

거래를 등록하면 마찬가지로 **보유 상태 · 가계부 · 보유 기간 통계**가 함께 채워집니다.

---

## 게임 정보는 어디서 오나

**BoardGameGeek(BGG)** 의 게임 카탈로그를 씁니다.
인원수 · 플레이 시간 · 난이도 · 평점 · 확장 관계 같은 정보는 전부 여기서 옵니다.

게임 이름은 **정식 한글 발매명이 있으면 한글로**, 없으면 원어 그대로 보여 줍니다.
기계 번역은 하지 않습니다 → [3.3 게임 이름과 한글명 제안](../../03-games/korean-names/)

## 데이터는 어디에 저장되나

**계정에 저장됩니다.** 기기를 바꾸거나 앱을 다시 깔아도 같은 계정으로 로그인하면 그대로 있습니다.

{: .warning }
> 이 말은 **로그인 방식을 잘 고르는 게 중요하다**는 뜻이기도 합니다.
> 계정이 바뀌면 데이터도 따라오지 않습니다 → [1.2 설치와 로그인](../login/)

원한다면 백업 파일로 내보내 따로 보관할 수도 있습니다 → [11.2 백업](../../11-data-settings/backup/)

## 다른 앱과 다른 점

보드게임 기록 앱은 여럿 있지만, 나이스보드에만 있는 것들이 있습니다.

- **거래·가계부** — 게임뿐 아니라 슬리브·매트 같은 용품까지, 얼마 쓰고 얼마 회수했는지
- **선주문/펀딩** — 돈은 나갔는데 물건은 안 온 상태를 따로 관리
- **챌린지** — 10x10 같은 목표를 세우면 진행률이 자동으로 올라감
- **모임** — 자주 모이는 사람들을 묶어 리더보드와 모임별 전적
- **한글화** — 한국어 UI, 그리고 게임 한글명을 사용자들이 함께 정하는 커뮤니티 투표
