## 설치

[Google Play 스토어](https://play.google.com/store/apps/details?id=com.ralph.boardgame_tracker)에서 **나이스보드**를 검색해 설치합니다.

앱을 열면 로고와 함께 *"나이스 플레이, 나이스 보드!"*가 뜨고, 로그인 화면으로 넘어갑니다.
*"당신의 모든 보드게임 라이프를 기록하세요"*

---

## 로그인 방식 네 가지

| 방식 | 버튼 | 비밀번호 필요 | 다른 기기에서 이어 쓰기 |
|---|---|---|---|
| 이메일 | **이메일로 시작하기** | 예 (6자 이상) | 가능 |
| 네이버 | **네이버로 계속하기** | 아니요 | 가능 |
| Google | **Google 로 계속하기** | 아니요 | 가능 |
| 카카오 | **카카오로 계속하기** | 아니요 | 가능 |

어느 쪽을 골라도 기능 차이는 없습니다. 데이터는 전부 계정에 저장됩니다.

## 고르기 전에 알아 둘 것
{: .d-inline-block }

중요
{: .label .label-red }

**한 번 고른 로그인 방식은 계속 쓰셔야 합니다.**

같은 이메일 주소를 쓰더라도 **Google 로그인과 카카오 로그인은 서로 다른 계정**입니다.
방식을 바꾸면 빈 계정으로 시작하게 되고, 이전 데이터는 이전 계정에 남습니다.

{: .warning }
> **꼭 방식을 바꿔야 한다면** 먼저 [백업 파일을 내보낸 뒤](../../11-data-settings/backup/)
> 새 계정에서 가져오기로 복원하세요. 이게 계정 간에 데이터를 옮기는 유일한 방법입니다.

## 이메일로 가입하기

**이메일로 시작하기**를 누르면 **로그인 / 회원가입** 세그먼트가 있는 화면이 나옵니다.

회원가입에 필요한 것:

| 항목 | 조건 |
|---|---|
| 이메일 | |
| 비밀번호 | 6자 이상 |
| 비밀번호 확인 | |
| **표시 이름 (선택)** | *"플레이 기록에 표시되는 이름"* |

표시 이름은 나중에 **내 정보**에서 바꿀 수 있습니다.

### 비밀번호를 잊었다면

로그인 화면의 **비밀번호를 잊으셨나요?** → 이메일 주소 입력 → 재설정 메일이 갑니다.

{: .note }
> 메일이 안 보이면 **스팸함**을 확인하세요. 앱도 같은 안내를 보여 줍니다.

## 로그인한 뒤에 할 일

### 표시 이름 정하기

새로 가입하면 앱에 처음 들어갈 때 **"다른 사용자에게 보일 이름"** 확인 창이 한 번 뜹니다.
소셜 계정으로 가입하면 그 계정의 이름이 자동으로 들어오므로, 여기서 확인하고 바꿀 수 있습니다.
**이 이름으로 시작**을 누르면 다음부터는 뜨지 않습니다.

이미 쓰고 계신 분에게는 이 창이 뜨지 않습니다.
**내 정보 → 프로필 헤더의 이름을 탭**해서 언제든 바꿀 수 있습니다.

이 이름은 두 곳에 쓰입니다:

| 쓰이는 곳 | 누가 보나 |
|---|---|
| 플레이 기록의 "나" | 나만 |
| 한글명 제안자 표기 · 사용자 검색 | 다른 사용자 |

{: .warning }
> 실명을 드러내고 싶지 않다면 확인 창에서 바꿔 두세요.
> 기록·컬렉션·통계 같은 내 데이터는 이름과 무관하게 공개되지 않습니다.

### 프로필 검색 허용 (선택)

**내 정보 → 소셜 → 다른 사용자가 내 프로필을 검색하도록 허용**

켜면 다른 사용자가 이름이나 보드라이프 ID로 나를 찾아 친구로 연결할 수 있습니다.
끄면 검색에 나오지 않습니다. 기본은 꺼져 있습니다.

단, 이 설정은 **검색에 뜨는지만** 정합니다. 한글명을 제안하면 제안자 이름은
설정과 무관하게 제안 목록에 공개됩니다 — [3.3 게임 이름과 한글명 제안](../../03-games/korean-names/) 참고.

### 보드라이프 ID (선택)

보드라이프 계정이 있다면 **내 정보**에서 등록해 둘 수 있습니다.
친구 목록에서 서로의 보드라이프 프로필로 바로 갈 수 있게 됩니다.

## 로그아웃과 탈퇴

**내 정보 → 계정** 아래에 있습니다.

- **로그아웃** — 데이터는 그대로 남고, 다시 로그인하면 돌아옵니다
- **계정 탈퇴** — 데이터가 삭제됩니다. 두 단계 확인을 거치며 마지막에 **"탈퇴"**를 직접 입력해야 합니다

무엇이 지워지고 무엇이 남는지는 [11.5 계정 탈퇴](../../11-data-settings/account-deletion/)에 정리돼 있습니다.
