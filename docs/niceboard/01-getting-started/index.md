# 1. 시작하기
{: .no_toc }

나이스보드를 처음 열었다면 이 장부터 읽으세요.
앱이 무엇을 해 주는지, 로그인 방식은 어떻게 고르는지, 첫 기록은 어떻게 남기는지를 다룹니다.

| 절 | 내용 |
|---|---|
| [1.1 나이스보드는 어떤 앱인가요](what-is-niceboard/) | 다섯 개의 기둥 — 컬렉션 · 기록 · 거래 · 챌린지 · 인사이트 |
| [1.2 설치와 로그인](login/) | 로그인 방식 4종 비교. **고르기 전에 읽어 주세요** |
| [1.3 화면 지도와 공통 조작](screen-map/) | 다섯 개 탭의 구조 + 앱 전체에 공통으로 적용되는 조작 규약 |
| [1.4 퀵스타트: 첫 기록 5분](quickstart/) | 게임 담기 → 플레이 기록 → 통계 확인까지 |
| [1.5 기존 데이터 가져오기](import-existing-data/) | BGG 컬렉션 · BG Stats 백업에서 옮겨오기 |

{: .note }
> 급하다면 [1.4 퀵스타트](quickstart/)만 따라 해도 앱을 쓸 수 있습니다.
> 다만 [1.2 설치와 로그인](login/)의 **로그인 방식별 데이터 이전 가능 여부**는 나중에 되돌리기 어려우니 먼저 확인하는 편이 좋습니다.
