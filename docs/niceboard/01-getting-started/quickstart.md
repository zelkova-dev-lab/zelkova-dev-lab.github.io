# 1.4 퀵스타트 — 첫 기록 5분
{: .no_toc }

로그인을 마쳤다면 이 순서대로 따라 해 보세요.
게임 하나를 담고, 한 판을 기록하고, 통계가 생기는 것까지 확인합니다.

1. TOC
{:toc}

---

## 1단계 — 게임 담기 (1분)

1. 홈 화면 오른쪽 위 **🔍 돋보기**를 누릅니다
2. 검색창에 게임 이름을 **두 글자 이상** 넣으면 알아서 찾아 줍니다
   - 안 나오면 **엔터**를 눌러 BGG까지 넓혀 보세요
   - 한글 이름이 안 나오면 **원어(영문) 이름**으로 해 보세요
3. 결과 카드의 **보유 게임 추가**를 누릅니다

컬렉션 탭 **보유 중**에 들어가 있으면 성공입니다.

{: .note }
> 얼마에 샀는지도 남기고 싶다면 게임 상세로 들어가 **거래 이력 → 거래 추가**로 등록하세요.
> 그래야 가계부와 보유 기간 통계가 채워집니다 → [5.1](../../05-transactions/game-transactions/)

---

## 2단계 — 플레이 기록 남기기 (3분)

1. 홈 화면의 **새 플레이 기록**을 누릅니다
2. 위쪽 토글이 **바로 기록**인지 확인하고, 방금 담은 게임을 탭합니다
3. 기록 입력 화면에서 채웁니다

| 항목 | 어떻게 |
|---|---|
| **날짜** | 기본값은 오늘. 지난 판이면 탭해서 바꿉니다 |
| **장소** | 직접 입력. 다음부터 쓰려면 오른쪽 **장소로 등록** 아이콘을 누르세요 |
| **참가자** | **나** 한 명으로 시작합니다. **인원 추가**나 **모임** 버튼으로 함께한 사람을 넣으세요 |
| **점수 / 승패** | 템플릿에 따라 다릅니다. 우선 승자만 표시해도 됩니다 |

4. **저장**을 누릅니다 (아래 버튼 또는 오른쪽 위 💾)

`플레이 기록이 저장되었습니다.` 메시지가 뜨면 끝입니다.

{: .note }
> 점수 입력이 복잡해 보이면 그냥 넘어가도 됩니다.
> 날짜와 참가자만 있어도 온전한 기록이고, 나중에 편집할 수 있습니다.

---

## 3단계 — 결과 확인하기 (1분)

기록 하나로 여러 화면이 이미 바뀌었습니다.

| 어디를 보면 | 무엇이 |
|---|---|
| **홈** | 최근 플레이 카드에 방금 판이 뜹니다. 히트맵에도 칸 하나가 칠해집니다 |
| **내 기록 → 플레이** | 목록에 기록이 있습니다 |
| **인사이트** | 총 플레이 1, 승률이 계산됩니다 |
| **게임 상세** | 플레이 통계 카드가 생겼습니다 |

![기록 직후의 홈 화면](/docs/niceboard/assets/screenshots/home-heatmap.webp){: .screenshot }
*히트맵에 칸이 칠해지고 챌린지 진행률도 함께 올라갑니다*

## 다음에 해 볼 것

익숙해졌다면 이 순서를 권합니다.

### 친구 등록하기

**내 정보 → 소셜 → 친구·모임 목록 → 친구 추가**

친구를 등록해 두면 기록할 때 이름을 고르기만 하면 되고,
**1:1 전적**이 자동으로 쌓입니다 → [9.1 친구 등록](../../09-friends-groups/friends/)

### 자주 가는 장소 등록하기

**내 정보 → 플레이 도구 → 장소 목록** → [9.4 장소](../../09-friends-groups/places/)

### 챌린지 하나 만들기

**챌린지 탭 → 오른쪽 위 +**

10x10(10개 게임을 10번씩)이 가장 흔한 시작점입니다.
기록을 남길 때마다 진행률이 자동으로 올라갑니다 → [7장 챌린지](../../07-challenges/)

### 라이브 세션 써 보기

다음 게임 모임 때 **라이브 세션**으로 시작해 보세요.
타이머와 점수패드를 쓰다가 끝내면 기록이 거의 다 채워진 채로 도착합니다 → [4.6 라이브 세션](../../04-play-records/live-session/)
