## BGG에서 가져오기
{: #bgg에서-가져오기 }

**내 정보 → 데이터 → BGG 컬렉션 동기화**

BGG 사용자 이름만 있으면 됩니다. 비밀번호는 필요 없습니다.

가져올 수 있는 것:

- **보유 게임** · **위시리스트**
- **이전 보유 → 처분 이력** (prev-owned 게임에 처분 거래 자동 생성)
- **플레이 기록** (BGG plays)
- **구매가·일자** (BGG private info에 적어 둔 값)

자세한 절차와 주의점은 [11.1 BGG 컬렉션 동기화](../../11-data-settings/bgg-sync/)에 있습니다.

{: .note }
> **여러 번 실행해도 안전합니다.** 이미 들어온 거래는 건너뜁니다.
> 처음에 컬렉션만 가져오고 나중에 플레이 기록을 추가로 가져와도 됩니다.

## BG Stats에서 가져오기
{: #bg-stats에서-가져오기 }

### 1. BG Stats에서 백업 파일 만들기

BG Stats 앱에서 백업(export)을 실행해 JSON 파일을 만듭니다.

### 2. 나이스보드에서 가져오기

**내 정보 → 데이터 → 백업 및 데이터 관리 → 가져오기**

파일을 고르면 앱이 **형식을 자동으로 알아보고** 유형별 건수를 미리 보여 줍니다.
확인하면 복원이 시작됩니다.

### 무엇이 넘어오나

| 항목 | 넘어오나 |
|---|---|
| 게임 목록 · 보유 상태 | ✅ |
| 플레이 기록 (참가자 · 점수) | ✅ |
| 장소 · 사람 | ✅ |
| 선주문 상태 | ✅ (선주문 거래로 들어옵니다) |
| 모임 · 챌린지 | ❌ (BG Stats에 없는 개념입니다) |
| 텍스트 항목 · 게임 공통 항목 | ❌ |

{: .note }
> 넘어오지 않는 것들은 **나이스보드 고유 기능**이라 BG Stats 백업에 담기지 않습니다.
> 가져온 뒤 앱에서 새로 만드시면 됩니다.

## 나이스보드 계정 간 이전
{: #나이스보드-계정-간-이전 }

로그인 방식을 바꾸거나 다른 계정으로 옮길 때 쓰는 방법입니다.

1. **이전 계정**에서 → 백업 및 데이터 관리 → **내보내기** → **나이스보드 전체 백업**
2. 파일을 안전한 곳에 저장
3. **새 계정**으로 로그인
4. 백업 및 데이터 관리 → **가져오기** → 그 파일 선택

{: .warning }
> **계정 간에 데이터를 옮기는 방법은 이것뿐입니다.**
> Google · 카카오 · 네이버 · 이메일은 서로 다른 계정이라
> 같은 이메일 주소를 써도 데이터가 자동으로 따라오지 않습니다 → [1.2 설치와 로그인](../login/)

## 가져오기는 덮어쓰기가 아닙니다

**병합**됩니다. 기존 데이터를 지우지 않고 합칩니다.

완전히 새로 시작하고 싶다면 먼저
[전체 데이터 초기화](../../11-data-settings/deleting/#전체-데이터-초기화)를 한 뒤 가져오세요.

---

## 실행 전에 자동으로 백업됩니다

가져오기와 BGG 동기화 **직전에** 현재 상태가 안전 스냅샷으로 저장됩니다.
결과가 마음에 안 들면 **가져오기 이전으로 되돌리기**로 돌아갈 수 있습니다 →
[11.2 백업 · 가져오기 · 되돌리기](../../11-data-settings/backup/)

{: .note }
> 스냅샷은 **기기 안에 최대 3개**만 보관됩니다.
> 중요한 데이터라면 백업 파일도 직접 내보내 따로 두세요.

## 가져온 뒤 확인할 것

| 확인 | 어디서 |
|---|---|
| 기록 건수가 맞나 | 내 기록 → 플레이 탭의 `전체 M건` |
| 보유 게임 수가 맞나 | 컬렉션 → 보유 중 탭의 숫자 |
| 참가자 이름이 친구와 연결됐나 | 내 정보 → 친구·모임 목록 |
| 통계가 잡히나 | 인사이트 탭 |

참가자 이름이 친구 목록과 다르면 전적이 안 잡힙니다.
필요하면 친구 이름을 기록 쪽에 맞춰 바꾸세요 → [9.3 전적 집계 규칙](../../09-friends-groups/stats-rules/)
