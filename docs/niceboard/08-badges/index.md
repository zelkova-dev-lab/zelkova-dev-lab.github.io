# 8. 업적 배지
{: .no_toc }

앱을 쓰다 보면 조건을 채운 순간 **배지**가 자동으로 찍힙니다.
따로 신청하거나 확인 버튼을 누를 필요가 없고, 획득하면 화면 아래에 축하 알림이 뜹니다.

| 절 | 내용 |
|---|---|
| [8.1 배지 시스템](system/) | 카테고리, 동/은/금 티어, 획득과 승급 규칙 |
| [8.2 배지 전체 목록](list/) | 배지별 조건과 티어 기준 표 |

배지 목록은 **내 정보 → 업적 배지** 카드에서 들어갑니다.

{: .note }
> 배지는 **한 번 얻으면 내려가지 않습니다.** 기록을 지워서 수치가 줄어도 이미 받은 티어는 유지됩니다.
