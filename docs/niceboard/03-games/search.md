**게임 검색** 화면. 홈이나 컬렉션 화면 오른쪽 위 **🔍 돋보기**로 들어갑니다.

## 세 가지 모드

위쪽 세그먼트로 고릅니다.

| 모드 | 무엇을 보여 주나 |
|---|---|
| **일반 검색** | 이름으로 찾기 |
| **Top 50** | BGG 랭킹 상위 50개 |
| **트렌딩** | BGG에서 지금 화제인 게임 |

---

## 일반 검색

**두 글자만 입력하면 알아서 찾아 줍니다.** 버튼을 누를 필요가 없습니다 →
[게임 검색은 두 글자부터 자동입니다](../../01-getting-started/screen-map/#게임-검색은-두-글자부터-자동입니다)

| 조작 | 어디까지 찾나 |
|---|---|
| 두 글자 이상 입력하고 잠깐 기다리기 | **앱에 등록된 게임**에서 찾습니다. 빠릅니다 |
| **엔터** 또는 검색창 오른쪽 **🌐 지구본** | **BGG까지** 넓혀서 찾습니다. 몇 초 걸립니다 |
| **✕** | 입력과 결과를 지웁니다 |

검색창 아래 회색 한 줄이 **지금 어디까지 찾은 것인지** 알려 줍니다 —
*"앱에 등록된 게임에서 찾았어요 · 엔터를 누르면 BGG까지 찾아봐요"* / *"BGG까지 찾은 결과예요"*

{: .note }
> **한글로 안 나오면 원어(영문) 이름으로 해 보세요.**
> 한글 이름은 앱에 등록된 게임에서만 찾습니다 — BGG는 한글 이름을 모르기 때문입니다.
> 그래서 한글로 검색하면 지구본 대신 **🔄 다시 검색** 버튼이 보입니다.
> 정식 한글 발매명이 등록된 게임만 한글로 검색됩니다 → [3.3 게임 이름과 한글명 제안](../korean-names/)

검색어가 없거나 한 글자만 넣었을 때는 안내와 함께 **즐겨찾기** 목록이 나옵니다.
한 글자만 넣으면 *"두 글자부터 자동으로 찾아요 · 엔터를 누르면 바로 찾아요"* 가 뜹니다 —
한 글자로 찾고 싶으면 엔터를 누르면 됩니다.

## Top 50

두 줄의 칩으로 축을 고릅니다.

### 첫째 줄 — 장르

**전체** · 전략 · 테마·모험 · 추상전략 · 협력 · 추리·탐정 · 마피아·사회추리 · 파티 · 가족 · 어린이

### 둘째 줄 — N인 베스트

**1인 · 2인 · 3인 · 4인 · 5인+**

![게임 검색의 Top 50](/docs/niceboard/assets/screenshots/search-top50.webp){: .screenshot }
*칩 줄은 좌우로 스크롤됩니다 — 위는 장르, 아래는 N인 베스트*

BGG 사용자들이 "이 인원수가 최적"이라고 투표한 게임 중 랭킹 상위를 보여 줍니다.
**"3인 보드게임 뭐 사지?"**에 답하는 축입니다.

{: .note }
> **전체** 탭에서는 카드 왼쪽 위 주황 메달이 곧 BGG 전체 순위입니다.
> 장르·트렌딩·검색 결과에서는 별도로 네이비 트로피에 전체 순위가 붙습니다.

---

## 필터

검색창 오른쪽 **필터 버튼**(활성 개수가 뱃지로 표시됨)으로 엽니다.

| 조건 | 기본값 |
|---|---|
| **보유 게임만 보기** | 꺼짐 |
| **최소 인원수** | 제한 없음 |
| **최대 플레이 시간** | 제한 없음 |
| **최소 평점** | 제한 없음 |
| **난이도** | 제한 없음 |
| **출판 연도** | 제한 없음 |
| **장르** | 선택 안 함 |

{: .warning }
> **필터 시트는 '필터 적용'을 눌러야 반영됩니다.** 조작하고 그냥 닫으면 버려집니다 →
> [공통 조작 규약](../../01-getting-started/screen-map/#필터-시트는-필터-적용을-눌러야-반영됩니다)

## 결과 카드 읽기

| 표시 | 뜻 |
|---|---|
| 왼쪽 위 **주황 메달** | 목록 안에서의 순위 |
| **네이비 트로피** | BGG 전체 순위 |
| **초록 배지** | 난이도(웨이트) |
| **베스트 N인** | BGG 투표에서 "최적"으로 뽑힌 인원수 |
| **추천 N인** | 최적은 아니지만 할 만한 인원수 |

---

## 결과에서 바로 담기

각 카드의 토글 버튼으로 컬렉션에 넣습니다.

- **보유 게임 추가 / 보유 취소**
- **위시리스트 추가 / 취소**
- **즐겨찾기에 추가 / 제거**

누를 때마다 확인 메시지가 뜹니다.

{: .note }
> **선주문/펀딩 항목은 여기에 없습니다.** 선주문은 결제 정보가 있어야 성립하므로
> 게임 상세의 **거래 추가**로만 등록합니다 → [2.5](../../02-collection/preorder/)
>
> 선주문 진행 중인 게임에서 보유를 누르면 **수령 완료** 절차로 넘어가고,
> 위시리스트를 누르면 *"선주문/펀딩 진행 중인 게임입니다. 취소는 컬렉션 선주문 탭에서 할 수 있어요."* 안내가 나옵니다.

## 결과가 없을 때

| 메시지 | 뜻 |
|---|---|
| `검색 결과가 없어요` | 이름을 다시 확인하거나, 아직 안 찾아봤다면 **엔터**로 BGG까지 넓혀 보세요 |
| `영문 이름으로 검색하면 BGG에서 찾을 수 있어요` | 한글로 찾다가 못 찾았을 때 함께 뜹니다. 원어 이름으로 다시 해 보세요 |
| `검색하지 못했어요` | 결과가 0건인 게 아니라 **조회 자체가 실패**한 것입니다. 네트워크를 확인하고 다시 시도하세요 |
| `두 글자부터 자동으로 찾아요 · 엔터를 누르면 바로 찾아요` | 한 글자만 입력한 상태입니다. 오류가 아닙니다 |
| `Top 50을 가져오지 못했습니다` | 네트워크 문제일 수 있습니다 |
| `트렌딩 데이터가 없습니다.` | 잠시 후 다시 시도해 보세요 |
