## 컬렉션 토글 세 개

| 아이콘 | 뜻 |
|---|---|
| 북마크 | **즐겨찾기** |
| 하트 | **위시리스트** |
| 라이브러리 | **보유** |

누르면 확인 메시지가 뜹니다.

### 선주문 중이면 다르게 보입니다

선주문/펀딩이 진행 중이면 토글 줄 왼쪽에 **주황색 상태 칩**이 나옵니다.

- `선주문 · 수령 예정 2026.6.20`
- 예상일을 모르면 `선주문/펀딩 배송 대기`

**이 칩을 탭하면 곧바로 수령 완료 절차**로 들어갑니다 → [2.5](../../02-collection/preorder/)

## 스탯 줄

인원수 · 플레이 시간 · 평점 · 난이도(웨이트) · BGG 랭크가 나옵니다.
전부 BGG 카탈로그 정보입니다.

## 장르와 분류

- **장르 칩** — 나이스보드가 정리한 한국형 장르 (전략 · 테마·모험 · 협력 등)
- **BGG 원본 분류** — 접혀 있고, 펼치면 BGG의 카테고리와 메카닉이 그대로 나옵니다

## 플레이 통계 요약

기록이 하나라도 있으면 나옵니다.

- 총 플레이 / 내 승률 / 최근 플레이
- 아래 한 줄 미리보기 — `최다 역할 OOO · N회` 또는 `최다 방식 OOO · N판`

**카드를 탭하거나 상세 통계 버튼**을 누르면 게임 통계 화면으로 갑니다 → [6.2](../../06-insights/game-stats/)

## 거래 이력

이 게임을 사고판 기록이 시간순으로 쌓입니다. 거래가 없어도 카드는 항상 보입니다.

| 요소 | 설명 |
|---|---|
| 헤더 | 건수 `N건` + 손익 합계 |
| 펼침 | 2건 이하면 자동으로 펼쳐지고, 3건 이상이면 접힙니다 |
| **거래 추가** | 새 거래 입력 → [5.1](../../05-transactions/game-transactions/) |
| 거래 행 **탭** | 편집 |
| 거래 행 **길게 누르기** | 삭제 |
| 수령 전 선주문 행 | 편집 대신 **수령** 버튼 |

수령을 마친 선주문 거래에는 `선주문/펀딩` 뱃지와 수령일이 계속 남습니다.

## 확장 관계

| 섹션 | 언제 |
|---|---|
| **본판** | 이 게임이 확장일 때 — 본판으로 가는 링크 |
| **보유 중인 확장** | 이 게임의 확장을 갖고 있을 때 |
| **확장** | 이 게임의 모든 확장. 기본 접힘, `더보기 (N)`으로 펼침. 가진 것에는 `보유` 뱃지 |

자세한 내용은 [2.4 본판과 확장](../../02-collection/expansions/)에 있습니다.
