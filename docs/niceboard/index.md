# 나이스보드 사용설명서
{: .no_toc }

**나이스 플레이, 나이스 보드!**

나이스보드는 보드게임 **컬렉션 · 플레이 기록 · 거래 이력 · 챌린지**를 한 앱에서 관리하는 안드로이드 앱입니다.
BoardGameGeek(BGG) 데이터를 카탈로그로 쓰고, 화면은 전부 한국어입니다.

[Google Play 에서 받기](https://play.google.com/store/apps/details?id=com.ralph.boardgame_tracker){: .btn .btn-primary }
[5분 만에 첫 기록 남기기](01-getting-started/quickstart/){: .btn }

## 이런 걸 할 수 있어요
{: .no_toc }

| | 무엇을 | 어디서 |
|---|---|---|
| 🎲 **플레이 기록** | 누가 몇 점으로 이겼는지, 어떤 역할·맵으로 몇 분 동안 놀았는지 | [4. 플레이 기록](04-play-records/) |
| 📚 **컬렉션 관리** | 보유 · 위시리스트 · 즐겨찾기 · 선주문/펀딩을 흐름대로 | [2. 컬렉션 관리](02-collection/) |
| 💰 **보드게임 가계부** | 게임과 용품의 구매 · 방출 이력, 지출과 손익 | [5. 거래와 가계부](05-transactions/) |
| 📊 **통계와 인사이트** | 승률 · H-Index · 플레이 성향 · 장롱 지수 · 게임별 심층 통계 | [6. 통계와 인사이트](06-insights/) |
| 🏅 **챌린지와 배지** | 10x10 같은 목표를 세우고 자동으로 진행률 추적 | [7. 챌린지](07-challenges/) · [8. 업적 배지](08-badges/) |

여기에 **친구·모임별 전적**, **라이브 플레이 도구**(타이머·점수패드·카운터), **이미지 공유 카드**, **BGG 컬렉션 가져오기**, **백업·복원**까지 들어 있습니다.

## 도움이 필요하면
{: .no_toc }

앱 안에서 바로 보낼 수 있습니다. **내 정보 → 지원 → 의견 보내기**에서 버그 제보나 개선 제안을 남기면
앱 버전·기기 정보가 함께 전달되고, 답변은 **내 정보 → 지원 → 내 의견 내역**에서 확인할 수 있습니다.
자세한 방법은 [12.4 의견 보내기](12-faq/feedback/)를 참고하세요.

- [개인정보처리방침](/policy/niceboard/privacy/)
