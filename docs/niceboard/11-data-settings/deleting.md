## 유형별 데이터 삭제

원하는 종류만 골라 지웁니다. 각 행에 **현재 건수**가 표시됩니다.

| 유형 | 지우면 |
|---|---|
| **플레이 기록** | 모든 판 기록. 통계·챌린지 진행률이 초기화됩니다 |
| **게임 컬렉션** | 컬렉션과 **거래 이력까지 함께** |
| **용품** | 용품과 그 거래 |
| **챌린지** | 모든 챌린지 |
| **업적 배지** | 획득 이력. 조건을 이미 채웠다면 다시 획득됩니다 |
| **친구** | 친구 목록. **모임은 남지만 멤버 구성은 함께 비워집니다** |
| **모임** | 모임만. **친구 목록은 그대로** |
| **장소** | 등록된 장소. 기록의 장소 텍스트는 유지됩니다 |
| **점수 시트 템플릿** | 내가 만든 템플릿 |

각 행에 부작용 안내가 붙어 있으니 읽고 진행하세요.

{: .note }
> **업적 배지 삭제는 사실상 초기화 버튼입니다.**
> 지워도 조건을 이미 충족한 배지는 다음 재판정 때 자동으로 다시 획득됩니다.

## 전체 데이터 초기화
{: #전체-데이터-초기화 }

앱을 처음 설치한 상태로 되돌립니다.

지워지는 것: 위 9종 전부

**남는 것**:

- 계정 자체 (로그인 상태 유지)
- 프로필 (이름 · 보드라이프 ID · 공개 설정)
- 커뮤니티 기여물 (한글명 제안 · 공유한 점수 시트)

{: .warning }
> 확인 창을 지난 뒤 **"초기화"라고 직접 입력**해야 실행됩니다.
> 실수로 누르는 것을 막기 위한 마지막 단계입니다.

## 어떤 걸 골라야 하나

| 상황 | 해야 할 일 |
|---|---|
| 테스트로 넣은 기록만 정리 | **플레이 기록** 삭제 |
| 가계부만 다시 시작 | **게임 컬렉션** 삭제 (거래도 함께 지워집니다) |
| 방금 한 가져오기가 잘못됨 | 삭제 말고 [되돌리기](../backup/#가져오기-이전으로-되돌리기) |
| 백업 파일로 깨끗하게 복원 | **전체 데이터 초기화** → 가져오기 |
| 앱을 그만 쓰고 싶음 | [11.5 계정 탈퇴](../account-deletion/) |

## 거래를 지우는 것과 게임을 처분하는 것

헷갈리기 쉬운 부분입니다.

| 하는 일 | 결과 |
|---|---|
| 게임의 **거래를 전부 삭제** | 가계부에서만 빠지고, **보유 표시와 게임 항목은 남습니다** |
| 컬렉션에서 **휴지통** | 그 목록에서만 빠집니다. 거래 이력은 남습니다 |
| **게임 컬렉션 전체 삭제** | 게임과 거래 이력이 **모두** 사라집니다 |

용품만 예외입니다 — **마지막 거래를 지우면 용품 자체가 사라집니다.**
