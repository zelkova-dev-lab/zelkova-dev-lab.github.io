# 11.5 계정 탈퇴
{: .no_toc }

**내 정보 → 계정 → 계정 탈퇴**

1. TOC
{:toc}

---

## 절차

두 단계로 확인합니다.

1. **무엇이 삭제되는지** 목록을 보여 줍니다
2. 마지막 확인 — *"확인을 위해 아래 칸에 "탈퇴" 라고 입력해 주세요."*

{: .warning }
> 탈퇴하면 **되돌릴 수 없습니다.**
> 남기고 싶은 것이 있다면 먼저 [백업 파일을 내보내](../backup/) 두세요.

---

## 삭제되는 것

| 대상 |
|---|
| 플레이 기록 |
| 게임 컬렉션과 거래 이력 |
| 용품과 거래 이력 |
| 점수 시트 템플릿 |
| 친구 · 모임 · 장소 |
| 챌린지 |
| 업적 배지 |
| 프로필 정보 |
| 다른 사용자에게 보이던 공개 프로필 |
| 이 기기에 저장된 안전 스냅샷 |

로그인 계정 자체도 함께 삭제됩니다.

---

## 남는 것

{: .note }
> **커뮤니티에 기여한 내용 일부는 남습니다.**
> 다른 사용자가 이미 쓰고 있는 것이라, 지우면 그 사람들에게 영향이 가기 때문입니다.

| 대상 | 왜 남나 |
|---|---|
| **한글명 제안과 표** | 다른 사용자의 투표 결과가 뒤집히지 않도록 |
| **공유한 점수 시트** | 이미 받아 간 사람들의 사본이 있음 |
| **보낸 의견(피드백)** | 접수된 버그 리포트는 보존됩니다 |

이 중 지우고 싶은 것이 있다면 **탈퇴하기 전에** 각 화면에서 먼저 삭제하세요.

| 무엇 | 어디서 |
|---|---|
| 한글명 제안 | 내 정보 → 플레이 도구 → **내 한글명 제안** → 제안 취소 |
| 커뮤니티 점수 시트 | 내 정보 → 플레이 도구 → **내 커뮤니티 시트** → 삭제 |

---

## 다시 로그인하라고 나올 때

보안상 **최근에 로그인한 상태**여야 탈퇴할 수 있습니다.
`requires-recent-login` 같은 안내가 나오면 로그아웃 후 다시 로그인한 뒤 시도하세요.

---

## 탈퇴 말고 다른 방법

| 원하는 것 | 방법 |
|---|---|
| 데이터만 비우고 계속 쓰기 | [전체 데이터 초기화](../deleting/#전체-데이터-초기화) |
| 잠시 안 쓰기 | 그냥 로그아웃 (데이터는 그대로 유지됩니다) |
| 다른 계정으로 옮기기 | [백업 내보내기](../backup/) → 새 계정에서 가져오기 |
