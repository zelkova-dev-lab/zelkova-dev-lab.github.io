# 11.1 BGG 컬렉션 동기화
{: .no_toc }

BoardGameGeek 계정에 있는 컬렉션과 플레이 기록을 통째로 가져옵니다.

**내 정보 → 데이터 → BGG 컬렉션 동기화**

1. TOC
{:toc}

---

## 가져올 수 있는 것

BGG 사용자 이름을 넣고 원하는 항목을 체크합니다.

| 항목 | 설명 |
|---|---|
| **보유 게임** | BGG의 owned 게임을 컬렉션 보유로 |
| **위시리스트** | BGG 위시리스트를 위시리스트로 |
| **이전 보유 → 처분 이력** | BGG prev-owned 게임에 처분 거래를 자동 생성 |
| **플레이 기록** | BGG의 plays 기록을 플레이 기록으로 |
| **구매가·일자 함께 가져오기** | BGG private info(가격·취득일)로 구매 거래를 만듭니다 |

---

## 실행하기

**동기화 시작**을 누르면 단계별 진행률이 나옵니다
(`플레이 기록 — N / M 페이지 가져오는 중`, `컬렉션에 적용 중`).

시간이 걸릴 수 있습니다. BGG 서버 요청 속도에 제한이 있어 천천히 가져옵니다.

---

## 시작 전에 안전 스냅샷을 남깁니다

동기화 직전에 **현재 상태가 자동으로 저장**됩니다.
결과가 마음에 안 들면 [11.2 되돌리기](../backup/#가져오기-이전으로-되돌리기)로 돌아갈 수 있습니다.

{: .warning }
> 스냅샷 저장에 실패하면 이런 확인 창이 뜹니다 —
> *"안전 백업 저장 실패 … 계속 진행하면 이번 동기화를 '되돌리기'로 복구할 수 없습니다."*
> 이럴 때는 중단하고 먼저 [백업 파일을 내보내](../backup/) 두세요.

---

## 여러 번 돌려도 안전합니다

같은 거래(가격과 날짜가 같은 것)는 다시 만들지 않고 건너뜁니다.
이미 처분 이력이 있는 게임에 또 붙이지도 않습니다.

**선주문/펀딩 중인 게임은 아예 건드리지 않습니다.**
수령 처리는 사용자가 직접 하도록 남겨 두어, 결제가 두 번 잡히는 것을 막습니다.

---

## 결과 확인

완료되면 요약이 나옵니다 —
`동기화 완료! 보유 N개 중 M개 반영, … · BGG 누적 플레이 N회`

가져오지 못한 게임이 있으면 **실패한 게임 N개** 카드가 함께 나옵니다. 펼쳐서 확인할 수 있습니다.
일시적인 오류는 앱이 자동으로 몇 번 다시 시도합니다.

---

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| `Invalid username` | BGG 아이디 철자를 확인하세요 |
| 진행이 멈춘 것 같음 | BGG 서버가 데이터를 준비하는 중일 수 있습니다. 조금 기다려 보세요 |
| 일부 게임이 실패 | 다시 실행하면 대개 채워집니다 (이미 반영된 것은 건너뜀) |

---

## 알아 둘 점

{: .note }
> **동기화는 한 방향입니다 — BGG → 나이스보드.**
> 앱에서 기록한 내용이 BGG로 올라가지는 않습니다.

- BGG의 컬렉션 상태 중 owned · wishlist · prev-owned만 가져옵니다
- 가격 정보는 BGG의 private info에 입력해 둔 값을 씁니다
