## 내 정보 화면 구성

| 섹션 | 들어 있는 것 |
|---|---|
| **프로필 헤더** | 아바타 · 이름(탭하면 변경) · 보드라이프 ID |
| **내 활동** | 플레이 통계 · 컬렉션 통계 · 업적 배지 |
| **소셜** | 친구·모임 목록 · 유저 찾기 · 프로필 검색 허용 |
| **플레이 도구** | 장소 목록 · 내 점수 시트 관리 · 내 커뮤니티 시트 · 내 한글명 제안 |
| **데이터** | BGG 컬렉션 동기화 · 백업 및 데이터 관리 |
| **설정** | 챌린지 알림 · 화면 테마 |
| **지원** | 사용설명서 · 의견 보내기 · 내 의견 내역 |
| **계정** | 로그아웃 · 계정 탈퇴 · 앱 버전 |

맨 아래에 `나이스보드 {버전}`이 표시됩니다. 문의할 때 이 번호를 알려 주면 좋습니다.

---

## 이름 바꾸기

프로필 헤더의 **이름을 탭**합니다. 이름 아래에 **"다른 사용자에게 보이는 이름"** 이라고 적혀 있습니다.

이 이름이 플레이 기록의 "나"로 표시되고, **한글명 제안자 표기와 사용자 검색에도 그대로 쓰입니다.**
소셜 계정으로 가입했다면 그 계정의 이름이 자동으로 들어와 있을 수 있으니,
실명을 드러내고 싶지 않다면 여기서 바꾸세요.

---

## 보드라이프 ID

보드라이프 계정이 있다면 등록해 둘 수 있습니다.

- 친구 목록에서 서로의 보드라이프 프로필로 바로 갈 수 있습니다
- 다른 사용자가 **보드라이프 ID로 나를 검색**할 수 있습니다 (정확히 일치할 때)

---

## 프로필 검색 허용

**소셜 → 다른 사용자가 내 프로필을 검색하도록 허용**

*"허용 시 이름·보드라이프 ID 로 다른 사용자가 나를 찾을 수 있습니다."*

기본은 **꺼짐**입니다. 켜면 이름과 보드라이프 ID만 공개되며,
기록·컬렉션·통계는 공개되지 않습니다.

{: .warning }
> **이 설정은 "검색에 뜨는지"만 정합니다.**
> 한글명을 제안하면 제안자 이름은 이 설정과 무관하게 제안 목록에 공개됩니다.
> [3.3 게임 이름과 한글명 제안](../../03-games/korean-names/)을 참고하세요.

## 화면 테마

**설정 → 화면 테마** — **시스템 / 라이트 / 다크**

기본은 **시스템**으로, 안드로이드의 다크 모드 설정을 따라갑니다.
로그인 전에도 적용되고, 앱을 껐다 켜도 유지됩니다.

{: .note }
> 다크 모드에서도 **공유 이미지는 항상 밝은 종이색**으로 만들어집니다 →
> [10장 공유하기](../../10-sharing/)

## 챌린지 알림

**설정 → 챌린지 알림 받기**

연속 플레이 · 정기 플레이 · 마감 임박 세 종류의 리마인더를 켜고 끕니다.
자세한 내용은 [7.3 알림 설정](../../07-challenges/notifications/)에 있습니다.

---

## 앱 업데이트

Play 스토어에서 설치한 앱이라면, 새 버전이 나왔을 때 앱 안에서 알려 줍니다.
*"새 버전이 있습니다"* → **업데이트** → 백그라운드 다운로드 → **재시작**

{: .note }
> Play 스토어를 거치지 않고 설치한 경우(APK 직접 설치 등)에는 이 알림이 동작하지 않습니다.
