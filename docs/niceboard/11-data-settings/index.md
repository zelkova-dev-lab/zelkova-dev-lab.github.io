# 11. 데이터 관리와 설정
{: .no_toc }

내 데이터는 계정에 저장되어 **기기를 바꿔도 그대로 따라옵니다.**
그 데이터를 가져오고 · 내보내고 · 되돌리고 · 지우는 방법, 그리고 앱 설정을 다룹니다.

| 절 | 내용 |
|---|---|
| [11.1 BGG 컬렉션 동기화](bgg-sync/) | BGG 계정에서 보유·위시·플레이 기록 가져오기 |
| [11.2 백업 · 가져오기 · 되돌리기](backup/) | 백업 형식 2종, 병합 복원, 자동 안전 스냅샷 |
| [11.3 삭제와 초기화](deleting/) | 유형별 삭제 9종, 전체 데이터 초기화 |
| [11.4 설정](settings/) | 화면 테마, 챌린지 알림, 프로필 공개, 보드라이프 ID |
| [11.5 계정 탈퇴](account-deletion/) | 무엇이 지워지고 무엇이 남는지 |

{: .warning }
> 가져오기와 되돌리기는 데이터를 크게 바꿉니다.
> 앱이 실행 직전에 **자동 안전 스냅샷**을 남기지만, 중요한 데이터라면 먼저 백업 파일을 직접 내보내 두세요.
