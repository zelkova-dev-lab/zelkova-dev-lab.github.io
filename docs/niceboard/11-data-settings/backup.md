## 백업 내보내기

**내보내기**를 누르면 형식을 고릅니다.

| 형식 | 담기는 것 | 언제 쓰나 |
|---|---|---|
| **나이스보드 전체 백업** | 모든 데이터 (점수 시트 · 거래 · 모임 · 챌린지 등) | **내 데이터를 온전히 보관**하거나 다른 계정으로 옮길 때 |
| **BG Stats 호환 백업** | BG Stats가 읽을 수 있는 범위 | BG Stats로 옮기거나 다른 도구에서 열 때 |

파일 저장 위치를 고르면 내보내기가 끝납니다.

{: .warning }
> **계정을 바꾸기 전에는 반드시 나이스보드 전체 백업을 내보내세요.**
> Google · 카카오 · 네이버 · 이메일은 서로 다른 계정이라 데이터가 따라오지 않습니다.
> 백업 파일이 계정 간에 데이터를 옮기는 유일한 방법입니다.

---

## 가져오기

**가져오기**를 누르고 백업 파일을 고릅니다.

1. 앱이 파일 형식을 **자동으로 알아냅니다** (나이스보드 전용 / BG Stats 호환)
2. 유형별 건수 미리보기가 나옵니다
3. 확인하면 복원이 시작됩니다

{: .note }
> **가져오기는 덮어쓰기가 아니라 병합입니다.**
> *"데이터 복원은 최신 데이터를 비교해 병합하는 방식으로 진행됩니다. 기존 데이터는 유실되지 않으며…"*
>
> 기존 데이터를 완전히 지우고 싶다면 먼저 [전체 데이터 초기화](../deleting/)를 하고 가져오세요.

가져오기 직전에도 **안전 스냅샷**이 자동으로 저장됩니다.

BG Stats 형식으로 가져올 때는 모임·챌린지·한글명 제안이 완료 안내에 나오지 않습니다 —
그 형식에 대응하는 개념이 없기 때문입니다.

## 가져오기 이전으로 되돌리기
{: #가져오기-이전으로-되돌리기 }

백업 파일 가져오기와 BGG 동기화 **직전에 자동 저장된 시점**으로 돌아갑니다.

목록에 `{출처} 직전 자동 저장`으로 표시되고, 각 행의 **되돌리기**를 누릅니다.
최신 3개까지 보관됩니다.

{: .warning }
> **그 시점 이후에 입력한 기록도 함께 사라집니다.**
> 가져오기를 한 뒤 며칠 동안 새로 남긴 기록이 있다면 그것도 없어집니다.
>
> 되돌리기 직전 상태도 스냅샷으로 저장되므로, 되돌리기를 다시 되돌릴 수는 있습니다.

되돌려도 남는 것:

- **업적 배지** — 한 번 얻은 배지는 유지됩니다
- **한글명 제안** — 커뮤니티 기여물이라 제외됩니다 (지운 제안이 되살아나거나 표가 롤백되지 않도록)

되돌리기가 중간에 실패하면 *"같은 시점으로 되돌리기를 다시 실행하면 이어서 복원"* 안내가 나옵니다.

---

## 스냅샷은 어디에 저장되나

**기기 안**에 저장됩니다. 계정마다 최대 3개까지 보관됩니다.

{: .warning }
> 기기를 바꾸거나 앱을 지우면 **스냅샷도 사라집니다.**
> 장기 보관이 필요하면 백업 파일을 직접 내보내 클라우드나 PC에 두세요.

## 어떤 방법을 언제 쓰나

| 상황 | 방법 |
|---|---|
| 정기적으로 안전하게 보관 | **나이스보드 전체 백업** 내보내기 |
| 계정 · 기기 바꾸기 | 전체 백업 내보내기 → 새 계정에서 가져오기 |
| BG Stats에서 넘어오기 | BG Stats에서 백업 → 나이스보드에서 가져오기 |
| BGG 컬렉션 가져오기 | [11.1 BGG 동기화](../bgg-sync/) |
| 방금 한 가져오기가 잘못됨 | **가져오기 이전으로 되돌리기** |
| 처음부터 다시 | [11.3 삭제와 초기화](../deleting/) |
