# 계정 및 데이터 삭제 안내

**앱 이름: 日留아프리**
**개발자: Zelkova Dev Lab**
**문의: zelkova.dev.lab@gmail.com**

---

## 1. 계정을 삭제하는 방법

앱 안에서 직접 삭제하실 수 있습니다. 별도로 메일을 보내실 필요가 없습니다.

1. 앱을 실행하고 로그인합니다.
2. 화면 아래 **더보기** 탭을 누릅니다.
3. 맨 위 **프로필**을 누릅니다.
4. 화면 아래쪽 **계정 삭제**를 누릅니다.
5. "계정과 프로필이 삭제되고 되돌릴 수 없어요"라는 안내를 확인하고 **삭제**를 누릅니다.
6. 본인 확인을 위해 한 번 더 로그인합니다(Google 계정 선택 또는 비밀번호 입력). 여기서 취소하면 아무것도 삭제되지 않습니다.

삭제는 **즉시 처리**되며, 처리된 뒤에는 되돌릴 수 없습니다.

앱을 지웠거나 로그인이 어려워 앱에서 삭제할 수 없는 경우에는 **zelkova.dev.lab@gmail.com** 으로 가입에 사용하신 이메일 주소(Google 계정 또는 이메일 로그인 주소)를 알려 주시면, 확인 후 **30일 이내**에 처리해 드립니다.

---

## 2. 삭제되는 데이터

계정을 삭제하면 아래 정보가 **즉시, 완전히 삭제**됩니다. 별도의 보관 기간은 없습니다.

- 계정 정보(로그인 식별자, 이메일 주소, 이메일 로그인의 비밀번호)
- 프로필(닉네임, 학생 구분, 목표 입학 연도, EJU·영어 시험 점수, 가입·수정 시각)
- 회원님이 쓴 한줄 댓글 전부
- 회원님이 다른 댓글에 남긴 신고 기록

---

## 3. 기기에 남는 데이터

찜한 대학·학과, 출원함, 최근 본 항목, 화면 설정은 서버가 아니라 **회원님의 기기에만 저장**되어 있어 계정을 삭제해도 기기에 남습니다. 이 정보는 앱을 삭제하거나, 기기의 "설정 → 애플리케이션 → 日留아프리 → 저장공간 → 데이터 삭제"로 지울 수 있습니다.

여러 기기에서 관심 목록을 함께 쓰는 동기화 기능이 제공된 뒤에는, 서버에 저장된 관심 목록도 계정 삭제 때 함께 삭제됩니다.

---

## 4. 계정을 유지하면서 데이터만 지우는 방법

계정을 삭제하지 않고도 아래 데이터를 직접 지울 수 있습니다.

- **한줄 댓글 삭제**: 내가 쓴 댓글 오른쪽의 **⋮** 메뉴에서 **삭제**를 선택합니다. 지운 댓글은 즉시 완전히 삭제되며 복구할 수 없습니다.
- **프로필 내용 지우기**: "더보기 → 프로필"에서 닉네임·학생 구분·목표 입학 연도·시험 점수 칸을 비우고 저장합니다.
- **찜·출원함 지우기**: 내 목록 화면에서 항목을 하나씩 해제하거나, 위 3번 방법으로 앱 데이터를 지웁니다.

전체 댓글을 한 번에 삭제하고 싶으시면 zelkova.dev.lab@gmail.com 으로 요청해 주시면 **30일 이내**에 처리해 드립니다.
