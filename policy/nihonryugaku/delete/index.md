## 1. 계정을 삭제하는 방법

앱 안에서 직접 삭제하실 수 있습니다. 별도로 메일을 보내실 필요가 없습니다.

1. 앱을 실행하고 로그인합니다.
2. 화면 아래 **MY** 탭을 누릅니다.
3. 맨 위 **프로필**을 누릅니다.
4. 화면 아래쪽 **계정 삭제**를 누릅니다.
5. "계정과 프로필이 삭제되고 되돌릴 수 없어요"라는 안내를 확인하고 **삭제**를 누릅니다.
6. 본인 확인을 위해 한 번 더 로그인합니다(Google 계정 선택 또는 비밀번호 입력). 여기서 취소하면 아무것도 삭제되지 않습니다.

삭제는 **즉시 처리**되며, 처리된 뒤에는 되돌릴 수 없습니다.

앱을 지웠거나 로그인이 어려워 앱에서 삭제할 수 없는 경우에는 **zelkova.dev.lab@gmail.com** 으로 가입에 사용하신 이메일 주소(Google 계정 또는 이메일 로그인 주소)를 알려 주시면, 확인 후 **30일 이내**에 처리해 드립니다.

## 2. 삭제되는 데이터

계정을 삭제하면 아래 정보가 **즉시, 완전히 삭제**됩니다. 별도의 보관 기간은 없습니다.

- 계정 정보(로그인 식별자, 이메일 주소, 이메일 로그인의 비밀번호)
- 프로필(닉네임, 학생 구분, 목표 입학 연도, EJU·영어 시험 점수, 출생 연도·성별·병역·거주 지역·공부 방법, 통계 사용 동의 기록, 가입·수정 시각 — 이미 만들어진 학과별 통계에서는 다음 집계 때 빠집니다)
- 회원님이 쓴 한줄 의견 전부
- 회원님이 다른 한줄 의견에 남긴 신고 기록
- 회원님이 게시판에 쓴 글과 댓글 전부(회원님의 글에 달린 다른 사용자의 댓글도 함께 삭제됩니다)
- 회원님이 게시판 글·댓글에 남긴 신고 기록
- 회원님이 등록한 합격·지원 결과 전부(이미 만들어진 학과별 통계에서는 다음 집계 때 빠집니다)
- 서버에 저장된 관심 목록(찜한 대학·학과, 출원함 — 이미 만들어진 대학별 찜한 사람 수 통계에서는 다음 집계 때 빠집니다)

## 3. 기기에 남는 데이터

최근 본 항목, 화면 설정, 관심 목록의 사본은 **회원님의 기기에 저장**됩니다. 계정을 삭제하면 **삭제를 진행한 기기**에 있는 그 계정의 값은 함께 지워집니다.

같은 계정으로 로그인했던 **다른 기기**에는 사본이 남아 있을 수 있습니다. 그 기기에서는 앱을 삭제하거나, 기기의 "설정 → 애플리케이션 → 日留아프리 → 저장공간 → 데이터 삭제"로 지울 수 있습니다.

## 4. 계정을 유지하면서 데이터만 지우는 방법

계정을 삭제하지 않고도 아래 데이터를 직접 지울 수 있습니다.

- **한줄 의견 삭제**: 내가 쓴 의견 오른쪽의 **⋮** 메뉴에서 **삭제**를 선택합니다. 지운 의견은 즉시 완전히 삭제되며 복구할 수 없습니다.
- **게시판 글·댓글 삭제**: 화면 아래 "커뮤니티" 탭의 게시판에서 내가 쓴 글 또는 댓글의 **⋮** 메뉴에서 **삭제**를 선택합니다. 글을 지우면 달린 댓글도 함께 지워지며 복구할 수 없습니다.
- **합격·지원 결과 삭제**: "MY → 내 합격·지원 결과"에서 지울 결과 오른쪽의 휴지통 아이콘을 누르고 **삭제**를 선택합니다.
- **프로필 내용 지우기**: "MY → 프로필"에서 닉네임·학생 구분·목표 입학 연도·시험 점수 칸을 비우고 저장합니다. 출생 연도·성별·병역·거주 지역·공부 방법도 같은 화면에서 비우면(선택 해제) 다음 통계 집계부터 빠집니다.
- **찜·출원함 지우기**: "MY → 찜한 대학·찜한 학과" 화면과 "MY → 출원 일정" 화면에서 항목을 하나씩 해제합니다. 해제하면 서버에서도 지워집니다.

한줄 의견이나 게시판 글·댓글 전체를 한 번에 삭제하고 싶으시면 zelkova.dev.lab@gmail.com 으로 요청해 주시면 **30일 이내**에 처리해 드립니다.
